## Summary

Both areas are already tidy: named constants, small procedures, most comments explain the
rule. What is missing is the **technique docs a newcomer needs** (the files tell *what*,
not *why this design*), plus one stale comment and a few small duplications.

1. Stale doc: `system.pas:480` says "Writing is not buffered", which `TextFlush` made false
   for the Crt case (S1).
2. No file in `host/` explains the Worker / SharedArrayBuffer / `Atomics.wait` design as a
   whole; it is spread over four headers (H1).
3. The virtual clock (decision 38) is explained nowhere in `host/`; `runtime.js` and
   `worker.js` describe an injected clock but not why `sleep` advances it (H2).
4. `crt.pas` does not say in its header that screen state is kept in Crt on purpose
   (decision 39: so the host stays a dumb cell store and Pascal programs can read
   `WhereX`/`WindMin` without a host call), nor how Write is routed through the hooks.
5. A few duplicated or repeated constructs in `host/` (BS/LF/CR in two files, `cell` index
   formula three times), all fixable line-neutrally.
