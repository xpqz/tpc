## Departures from the original contract (the doc describes the code)

- `expr` and `stmt` return `R<()>` and mutate in place; they do not return a possibly-new handle.
  Nodes are rewritten by overwriting `kind` and `ty`.
- The only conversion node is `CharToStr`; `IntToReal`, `Kind::Conv` and `ConvOp` do not exist
  (`Real` is omitted, error 200).
- Constant folding yields `IntLit` and `StrLit`, no `RealLit`; a one-character string literal
  becomes `IntLit` of type Char.
- `Symbol` is `{kind, ty, val, taken, depth}`. Storage is a `SymKind` variant (`Var`, `Local`,
  `Frame`, `Ref`, `FrameRef`), not a separate `Local(n)/Frame/Global` field; `captured` and
  `addr_taken` are one flag, `taken`. There are no `Param`, `Field`, `Unit` or `Func` symbol kinds
  (parameters are `Local`/`Ref`; fields live in `Type::Record`; functions are `Routine` with `func`).
- Types: `Str(n)` is created per form (no interning); only `Proc` is interned. `Types` has no `Real`
  or `Set`/`Ptr` yet; `Array` is one-dimensional (`a[i, j]` nests).
- String operators are lowered in codegen, not by tree rewriting; only `Delete`, `Insert` and
  `Concat` are rewritten by the checker.
- Names are interned uppercase by `Ast::intern` (parser side), not the lexer.
- `Diag` lives in `driver.rs`; `Info` (types, syms, routines, data_end, helpers) is the checker's output.
- Pipeline gained System loading (decision 11) and helper binding.
