# #70 Console ReadLn in the browser without Crt

Branch: `70-console-readln-in-the-browser-without-crt`. Decision 46.

## RED

Intended behaviour: in the browser host (`host/worker.js`) `readline` returns -2 ("no line
input"); System's console line input then reads `readkey` with a Pascal line editor that
echoes through the console writer (printable characters, Backspace, Enter; Esc clears the
line, extended and other control keys are ignored, as in Crt's `EditLine`). The Node runner
is unchanged.

Tests:

- `tests/programs/readln_browser.pas`: `ReadLn(String)` then `ReadLn(A, B)` then
  `WriteLn('hello ', Name, ' ', A + B)`. `tools/tp5.sh` with input `Bob` / `12 30` prints
  `name? a b? hello Bob 42` (checked).
- `tests/host/console_readln.mjs` (run by `cargo test --test host_browser`, test
  `console_readln_without_crt_reads_typed_lines`): runs the program in the real worker entry
  (`host/worker.js` in a worker thread) with scripted keys and compares the grid rows:
  typed string and numbers; Backspace editing; Esc plus an extended key plus Tab ignored;
  empty line gives an empty string; Backspace on an empty line does nothing; negative: a bad
  number is runtime error 106 (`done: { code: 106, halted: true }`).
- `tests/host/browser/readln.mjs` (added to `tests/host/browser/run.mjs`): the same program in
  Chrome and Firefox, keys through the real input pipeline, including Backspace; checks rows 0
  to 2 of the screen. Added `backspace` and `space` to `KEYS` in `chrome.mjs`.

How they fail today: `readline` returns -1 in the worker, so ReadLn sees end of input and
the program ends at once; the grid is `name? a b? hello  0` on row 0 (all six node tests
fail on the row assertions; the 106 test fails on the result), and the browser test times
out waiting for the prompt row `name?`.

Commands:

- `TP5C=... node tests/host/console_readln.mjs`: 6 of 6 fail as described.
- `BROWSER=chrome node tests/host/browser/readln.mjs`: fails, "timed out waiting for the prompt".
- `tools/loc.sh`: System, Crt, Dos subset 1043 / 1500; Host glue 599 / 600; total 9666.
