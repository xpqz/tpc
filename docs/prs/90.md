# #90 Assign with an empty name is the console

Branch: `90-assign-with-an-empty-name-is-the-console`. SWAG issue 8.

## Tests (all expected output from `tools/tp5.sh`)

- `tests/lang/swag_assign_empty_name_is_stdin` (the reproducer, removed from `PENDING`).
- `tests/lang/assign_empty_reads_numbers`: `ReadLn(f, a, b)` then `Read(f, a)` from `''`.
- `tests/lang/assign_empty_eof`: line loop until `Eof(f)`, then `Eof`/`Eoln` are True.
- `tests/lang/assign_empty_output`, `assign_empty_append`: `Rewrite`/`Append` write standard
  output; `Close` leaves the console usable.
- `tests/lang/assign_empty_wrong_direction`: `Write` on a Reset file is 105, `ReadLn` on a
  Rewrite file is 104.

RED: all failed with `Runtime error 002` (`cargo test --test lang`).

Probed and left out of the tests, recorded as deviation D42: TP block-buffers standard input
(a second reader or a second `Reset` finds the data consumed) and writes `''` output through
DOS, so under Crt `WhereX`/`WhereY` do not see it and typed input is echoed by DOS.

## Change

`runtime/system.pas`: `OpenConsole`, and `OpenFile` switches to console mode when the name is
empty (input mode for Reset, output for Rewrite/Append), before the open-file checks. Read,
Eof, Eoln and write paths already handled console modes.
