# #49 Phase 5 test corpus

Branch `49-phase-5-test-corpus`. Test files only: no change under `compiler/src`, `runtime/`, `host/` or the drivers.
`tools/loc.sh` total 5377 / 15000 before and after (delta 0).

## Method

- Every `.out` and `.err` was produced by `tools/tp5.sh` (real TP 5.0 under DOSBox-X) on the committed program with the
  decision-26 layout (`DIR/NAME.pas`, `DIR/NAME/` aux files in DOS 8.3 upper case, optional `DIR/NAME.in`). No expectation is
  hand-written; fpc supplied none. Programs TP5 rejected were fixed or dropped (list under findings). The `.out` of the `rt`
  programs are normalised as in #39 and #48 (`Runtime error 002`, three digits, no address). `.err` is `N LINE`, or
  `N LINE FILE` for an error in a unit or include (decision 28).
- Aux text files are CRLF and use the extensions `.TXT`/`.DAT` (byte-exact through `.gitattributes`); `.PAS`/`.INC` aux files are
  LF in the repo (`tp5.sh` converts); `.in` files are LF. Special fixtures: `EOFMARK.TXT` holds a ^Z byte,
  `NOEND.TXT` has no final line end, `WIDE.TXT` has a 300 character line, `EMPTY.TXT` and `console_eof_on_empty_input.in` are empty.
- Rules kept: GetDate/GetTime values are never printed; no program reads a variable it has not assigned (TP5 does not clear
  globals); one negative per rule (decision 22); skipped conditional text has no lex errors; console input comes from `NAME.in`.
- Counts of new programs: `lang` 122, `abi` 13, `rt` 20, `neg` 37 (192 in all). All are in the `PENDING` lists except three
  `neg` programs the current compiler already rejects with the TP5 number and line (`dos_unit_name_without_uses`,
  `unit_qualified_name_of_unit_not_used`, `unit_uses_clause_after_declarations`). New PENDING lines: lang 122, abi 13, rt 20,
  neg 34. `lang`/`abi` is 135 programs against the brief's 60-80: the issue lists many areas, and each program is small.
  Candidates to prune at the verdict are the weakest per area (for instance `ifdef_long_comment_form`,
  `include_file_with_comments_and_directives`, `unit_without_initialization_part`).

## TP5 findings (each pinned by a program)

1. **`initialization` is not TP5.** A unit's init part is `begin ... end.`; `initialization` is `Error 37: END expected` (`neg/unit_initialization_keyword`).
   The plan and the issue say `initialization`; the lang/abi/rt tests all use `begin`. The lead decides whether the compiler accepts it as an extension (deviation).
2. **Language limits that bit the corpus**: a function result cannot be a record, array, set or procedural type (34; use `var` parameters);
   no `const` parameters, no open-array parameters, no `High`/`Low`, no `nil` for a procedural variable (20); `Text`, `Real` etc. are type names, so a
   variable called `text` breaks a later `f: Text` (21); no procedural-typed constants (99).
3. **TP5 does not zero globals.** A global `Integer` that was never assigned held -16628 in a probe; the corpus assigns before it reads.
4. **A pending I/O error stops later I/O, console output included**, while `{$I-}` is on: after a failed `Reset`, `Write('x')` prints nothing until `IOResult`
   is called. `WriteLn('code ', IOResult)` therefore prints `103`, not `code 103`: the text is dropped before the argument is evaluated
   (`ioresult_pending_error_skips_following_io`). Every other program reads `IOResult` into a variable first.
5. **`Read(c)` returns the line end bytes**: CR, then LF; `Eoln` is true when the next byte is CR. The same holds for console input redirected from a file
   (`textfile_read_char_returns_line_end_bytes`, `console_read_chars_returns_line_end_bytes`). With the ABI's `readline` the runtime must synthesise CR LF.
6. **`Append` of a missing file is error 2** (`ioresult_append_to_missing_file_fails`, `rt/file_append_to_missing_file`); docs/abi.md section 8 says
   mode 2 creates it. `System` has to try an existing-file open first, or the contract changes.
7. Reading: `Read` of a number skips blanks, tabs and line ends; `1x` or `abc` is 106; `Read` at end of file gives 0 or '' with IOResult 0; `Read(Integer)` of `99999`
   wraps to -31073 with IOResult 0 (no range check); `Read(s)` takes the rest of the line without its end; `Read` into `String[5]` takes five characters and leaves the rest;
   a 255 character string takes 255 of a 300 character line and leaves 45 for the next `Read`.
8. Codes: Reset/Rewrite of a name with a missing directory 3 (`NODIR\X.TXT`, also `A:B.TXT` for a missing drive); Close of an assigned unopened file 103;
   `Read`/`ReadLn` on a closed or unopened file 104 (not 103); `Write` to a closed or input file 105; `Read` from an output file 104; `Reset` of a never assigned file 102;
   `Eof` of a never assigned file 104. Reset of a file that is already open is not an error.
9. `{$I-}` is local to its source file: a unit's `{$I-}` does not turn off checking in the program (`rt/file_io_checking_of_unit_does_not_leak_into_program`).
   The switch is positional: a `{$I-}` after the failing call does not help.
10. Conditionals: a symbol defined in a unit is not defined in the program, and the other way round; a symbol defined in an include is defined after it; an `$IF`
    must close in the file that opened it (129 at the include's line 1); `$ELSE` twice and `$ENDIF` after the final `end.` are accepted (not pinned);
    missing include is 15; an include in a statement part is 118; skipped text is only scanned for directives.
11. Includes: the default extension is `.PAS`; nesting works; the error line of a problem inside an include is in the include file (`N LINE BAD.INC`).
12. Units: the unit name must equal the file name (69, reported at the `uses` line in the program); a program file used as a unit is 84; `uses` after a declaration is 36;
    the same unit twice in one `uses` is 4 (not kept, same rule as other duplicates); the circular-interface error is reported in the file whose `uses` closes the cycle.
    Procedural values across units need `{$F+}` in the unit and the program (D11: the compiler ignores it).
13. Typed constants: a string longer than `String[n]` is cut silently; a record constant missing a field and a function call in an initializer were accepted by TP5 and are
    not tested; a typed constant is not a constant (133) in an array bound.
14. DOS accepts names such as `A B.TXT` and over-long names; `Assign(f, '')` binds the console. None is tested (the VFS contract rejects the first two).
