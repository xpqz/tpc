## Changes

- `runtime/dos.pas`: constants, types, `DosError`, `PackTime`, `UnpackTime`, `FSplit`, `FExpand`,
  `GetDir`. Pure Pascal string and bit work; no host change (Host glue stays 600 / 600).
- `tests/lang/PENDING`: `swag_dos_types` removed.
- `docs/subset.md`: supported list, omitted routines. `docs/deviations.md`: D39.

## Decisions

- Omitted, left undeclared (error 3): `FindFirst`, `FindNext`, `FSearch`, `DiskSize`, `DiskFree`,
  `ChDir`, `GetFAttr`, `GetFTime`: the host has no listing, disks or directory changes and no
  glue lines are free. `SearchRec` is declared, `DosError` exists and is never set.
- `FExpand`: the current directory of every drive is its root, which is what the oracle shows
  (probed: `C:\`, and `d:f` gives `D:\F`). Probing found: `..` at the root is dropped, an empty
  component from `\\` is kept, a trailing backslash is kept, `x\y\..` has none, `1:x` is drive
  `1`, `/` is not a separator. Recorded as D39.
- `GetDir(d)` gives `Chr(64 + d)` plus `:\` (0 is `C`); TP's output for drives 27 and 255 is
  garbage that the same formula reproduces, so those are not tested.
- `DosError` printed an uninitialised value in TP; here it is 0. Not tested.
- `FSplit` takes the first dot after the directory part (probed: `a.b.c` has extension `.b.c`).
- Locals of `FExpand` may not share a name with a parameter in any case (`Path`, `path`): the
  compiler reports error 4, as TP does.
