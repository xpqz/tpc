# #76 IDE View

Branch: 76-ide-view (worktree `worktrees/76-ide-view`).

## Stage 1: RED

### Interface the tests fix (unit `View`, `ide/view.pas`)

`uses Crt, Buffer` inside; the tests call only these four:

- `Reset`: top line 1, left column 1, no message, Insert mode; sets the bar colour and clears the
  whole screen (once, at start-up).
- `SetMessage(Text)`, `SetInsertMode(Insert)`: state for the status line.
- `Paint`: scrolls as little as needed so the cursor is inside the edit area, repaints the
  whole window, leaves the Crt cursor at the Buffer cursor.

Screen: row 1 menu bar (placeholder ` File  Edit  Run  Compile  Options`, attribute 70),
rows 2..24 edit area (23 lines, attribute 1E), row 25 status (attribute 70): `LINE:COL` at
column 2, `Insert`/`Overwrite` at column 14, the message from column 25, cut at column 79.

Decisions fixed by the tests (to be recorded as decision 45 by the lead):

- Repaint: always the whole window (25 writes). No change tracking; correctness first. The
  cost on a real screen is flicker-free enough because every row is one `Write`; if the IDE
  later feels slow, tracking the top line and only repainting the cursor line is the first step.
- Scrolling is minimal: moving above the top puts the cursor line on the top row; below the
  bottom puts it on row 24; columns likewise with the 80-column window.
- Tabs: Buffer stores `#9`; the View shows it as spaces to the next multiple of 8. The Crt
  cursor and horizontal scrolling use screen columns; the status line shows the Buffer column
  (character count), so `PosOf` and the status agree.
- Row 25 is written to column 79 only (a character at column 80 of the last row scrolls the
  screen); `Reset` colours the whole screen so that cell matches the bar.
- Other characters (control codes, #176 and up) are written as they are.

### Tests (`tests/lang/ide_view_*`, 22 programs; each `NAME.dirs` holds `ide`)

Each program does `Reset`, builds text with `InsertChar`, positions the cursor with
`SetCursor`/`PosOf`/`MoveUp`, calls `Paint`, and ends with the screen uncleared; the golden is
the screen dump (text rows, cursor, exit code, attribute runs), so all rows, the status line,
the cursor cell and the colours are compared.

- `empty_buffer`: empty edit area, `1:1`, cursor at row 2 column 1.
- `short_text_cursor_in_the_middle`: four lines, cursor 3:5, `3:5` in the status line.
- `cursor_at_end_of_text_without_final_break` / `..._after_final_break`: cursor at the end of
  the last line, and on the empty last line after a final break.
- `overwrite_indicator_and_message`; `message_longer_than_the_status_line_is_cut` (90
  characters, cut at column 79); `reset_forgets_message_and_clears_old_screen` (a second
  `Reset` after a full, scrolled, Overwrite screen: no leftovers).
- Vertical scrolling: `exactly_23_lines_do_not_scroll`, `scroll_down_by_one_at_line_24`,
  `scroll_down_past_row_24_to_line_60`, `scroll_up_only_as_far_as_needed` (100 lines: 1, 40,
  then 30:3: top is 30), `scroll_keeps_cursor_row_while_moving_inside_the_window` (ten
  `MoveUp` then two `MoveDown` after jumping to 50: the window does not move until the cursor
  leaves it), `repaint_after_deleting_text_blanks_leftover_rows` (40 lines cut to 4 lines),
  `typing_a_screenful_with_the_view_painting_each_line` (30 paints while typing).
- Horizontal scrolling: `long_line_scrolls_right_to_column_150` (200-column line, other rows
  empty), `long_line_cursor_at_column_80_and_81` (80 stays, 81 scrolls by one),
  `long_line_scrolls_back_left_when_cursor_returns` (200, 100, 90), `horizontal_scroll_shows_each_row_with_the_same_offset`.
- Tabs: `tabs_expand_to_multiples_of_eight` (tab first, after 2, after 7, after 8, two tabs;
  cursor after `ab` + tab), `tabs_cursor_column_is_screen_column_status_is_buffer_column`
  (`3` in the status, screen column 17), `tabs_in_a_long_line_scroll_by_screen_columns`.
- `control_characters_are_shown_as_they_are`: #1, #2 and the block characters.

No negative tests: the unit adds no language construct and has no error paths; the

## Stage 2: GREEN

Changes: `ide/view.pas` (unit `View`, the draft the goldens were made with, unchanged; no test
changed); decision 47 added to `docs/decisions.md` (whole-window repaint, minimal scrolling,

Design: `Paint` = `ScrollToCursor` (clamp TopLine and LeftColumn to keep the cursor inside),
then one `Write` per row from `VisibleCells` (tab expansion and horizontal cut), then the status
line from `StatusText`, then `GotoXY`. `ScreenColumnOf` is the only place that knows tab stops.
