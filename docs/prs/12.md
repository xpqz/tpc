# #12 WASM binary emitter

Branch: `12-wasm-binary-emitter`.

## Stage 1: RED

### API (`compiler/src/wasm.rs`, stubbed; `pub mod wasm;` in `lib.rs`)

```rust
pub const I32: u8 = 0x7F; I64 = 0x7E; F64 = 0x7C; VOID: u8 = 0x40;   // value / block types
pub const FUNC: u8 = 0; TABLE = 1; MEM = 2; GLOBAL = 3;              // export kinds
pub fn uleb(out: &mut Vec<u8>, v: u64);   // appends
pub fn sleb(out: &mut Vec<u8>, v: i64);   // appends; covers i32 and i64

pub struct Label(pub u32);                // Copy; nesting depth at which the block was opened
pub struct Code;                          // function-body builder
  Code::new() -> Code                     // depth 0; the function's final `end` is added by Module::func
  op(u8)                                  // no-immediate opcode (add, drop, unreachable, ...)
  idx(u8, u32)                            // opcode + uleb index (local.get/set/tee, global.get/set, call)
  i32_const(i32), i64_const(i64), f64_const(f64)
  mem(u8, align_log2: u32, offset: u32)   // loads and stores
  call_indirect(ty: u32)                  // table 0
  block(bt: u8) -> Label, loop_(bt) -> Label, if_(bt) -> Label
  else_(), end()
  br(Label), br_if(Label)                 // relative depth = current_depth - 1 - label.0
  (all but the label-returning ones return &mut Self for chaining)

pub struct Module;
  Module::new()
  ty(params: &[u8], results: &[u8]) -> u32          // interned: identical signature, same index
  import_func(module: &str, name: &str, ty: u32) -> u32   // function index
  func(ty: u32, locals: &[u8], body: Code) -> u32         // function index; locals RLE-encoded
  table(min: u32)  memory(min_pages: u32)
  global_i32(mutable: bool, init: i32) -> u32             // global index
  export(name: &str, kind: u8, idx: u32)
  elem(offset: u32, funcs: &[u32])  data(offset: u32, bytes: &[u8])
  finish(self) -> Vec<u8>                                 // canonical section order, empty ones omitted
```

Decisions stated by the tests:

- Imports are functions only and must precede defined functions (index space); `import_func`
  after `func` panics ("import after function").
- Structural misuse panics in the builder (plain `panic!`, kept in release since the compiler
  is `panic = "abort"`): `end` with no open block, `Module::func` with an open block, a
  second `end` after balance ("unbalanced"); `br`/`br_if` to a label at or above the current
  depth ("label"); `else_` when the innermost open block is not an `if` ("else").
- Node's validator is the second line of defence: `harness_rejects_*` check that a body missing
  its final `end` or with an unbalanced block is invalid, so the Node checks do detect it.
- One table (index 0), one memory, at most one of each; limits are min only (no max).
- Opcode constants are not part of the API; tests define the ones they use in
  `compiler/tests/common/mod.rs`. Codegen will decide whether to add a table to `wasm.rs`.

### Tests (`compiler/tests/`)

All fail today against the stub (every encoder is a no-op, `finish` returns an empty `Vec`,
`ty` returns 0, nothing panics). Failures are assertion mismatches (`left: []` vs the expected
bytes), the "should panic" tests do not panic, and the Node tests fail at their exact-bytes /
validate / result assertion. None fails to compile. Expected bytes are hand-derived from the
spec; the hand-written hello and block-depth expectations are themselves checked with
`WebAssembly.validate`, and the LEB vectors were decoded with an independent JS decoder
(BigInt) before commit.

`leb128.rs` (5 tests, all fail: output is empty)
- `unsigned_known_sequences`: 0, 1, 63, 64, 127, 128, 255, 300, 624485, u32::MAX, u64::MAX.
- `signed_known_sequences`: 0, -1, 63, 64, -64, -65, 127, -128, -123456, i32::MIN/MAX, i64::MIN/MAX.
- `encoders_append_to_existing_output`: appends, does not clear.
- `round_trip_around_every_group_boundary`: 2^k +- 2 for k in 0..64, both signs, uleb and sleb,
  against a test-side decoder (the decoder asserts non-empty input, so empty output fails).
- `encodings_are_minimal`: byte counts at the 1/2-byte boundaries.

`wasm_sections.rs` (24 tests, all fail: empty or wrong bytes, index 0 returned)
- Empty module is exactly the 8-byte header; unused sections omitted.
- Exact bytes: type (incl. i64/f64), import, function + code, two functions, locals
  RLE (`[i32,i32,f64]` -> `2 i32, 1 f64`; non-adjacent not merged), table, memory (incl. multi-byte
  page count), global (mutable with 65536, immutable -1), export (memory/global and function/table
  kinds), element (one and several funcs), data (one segment, several, empty segment).
- Section size uses multi-byte LEB (208-byte data section).
- Canonical section order regardless of call order (ids 1,3,4,5,6,7,10,11).
- Type interning: identical signatures share an index; params vs results distinguished.
- Function index space: imports first (0, 1), then defined functions (2, 3); import after func panics.

`wasm_blocks.rs` (12 tests, all fail: wrong bytes, or no panic)
- `br` from three-deep nesting emits depths 2, 1, 0; depth depends on the current depth;
  sibling blocks; `br_if` + `loop` labels; `if`/`else` keeps its label; block result types
  (i32, f64); Pascal-style `exit` block around nested ifs.
- Negative: `end` without block, function with open block, extra `end`, `br` to a closed
  label, `else_` outside `if` (all `should_panic` with the stated message).

`wasm_validate.rs` (10 tests; 8 fail; the 2 `harness_rejects_*` pass today because they feed
hand-written bytes to Node and test only the harness)
- `hello_module_exact_bytes`, `hello_module_validates_and_prints_ok` (imports `host.write`,
  memory, data, exported `main`; run in Node, stdout is `OK`: the Phase 0 exit test),
  `imports_and_exports_are_visible_to_node`.
- `stack_pointer_global_with_loads_and_stores`: global 0 as sp, frame alloc/free, i32
  load/store, result 21, sp restored to 65536.
- `call_and_call_indirect_through_table_and_element_segment`: direct call, `call_indirect`,
  trap stub in slot 0 raises a `RuntimeError`.
- `f64_arithmetic_memory_compare_and_convert`: f64 mul/add, store/load, `lt`, convert.
- `if_else_with_result_and_loop_with_exit_block`: if/else with i32 result; loop sum(10) = 55.
- `i32_and_i64_constants_round_trip_through_node`: extremes of both widths read back via Node.
- `harness_rejects_a_function_body_missing_its_final_end`, `..._unbalanced_block_in_a_body`.
