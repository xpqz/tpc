TP5 findings (probed):
- Global variables are **not** zero-initialised in this TP5 (a fresh `array of LongInt` prints garbage), so
  no test prints an uninitialised variable (a first draft did; removed).
- Limits: a structure is at most 65535 bytes (`array[0..65520] of Byte` is accepted, `array[1..300,1..300]
  of Integer` and a record of two 40000-byte arrays are 22); the sum of globals or of one routine's locals
  above 64 KB is 96 "Too many variables" (two `array[1..40000] of Byte`).
- A constant index outside the bounds is 76 (also through a `var` argument, `Q(rv[3].a)`); variable
  indexes are unchecked. `array[1..0]` is 28; missing `of` 54; unknown element type 3.
- Qualifiers: `a[1][2]` on a one-dimensional array and `a.x`, `r.a.b`, `F[1]` are 121; unknown or missing
  field names (also after `.` and for variant records) are 44; `with n do` on a non-record is 75; `with`
  fields are not visible after the statement (3); too many or too few indexes `a[1,2]` on a 1-D array and
  `a[1,2,3]` on a 2-D array are 93; indexing a 2-D array once and assigning is 26.
- Types: arrays, records and scalars are never assignment compatible with each other (26); two records of
  identical shape are distinct types (26); an array element or record field passed as a `var` of another
  type is 26, `Q(v[1])` for a `var` array parameter is 26; `Succ(array)` is 39; `if record` is 40.
- `for a[1] := 1 to 2` is accepted by TP5 (not tested).
- `SizeOf` of a record with a variant is the fixed part plus the largest variant (`Header` is 4).

## Intended behaviour (GREEN)

- Layout in `types.rs` only: one size and offset computation (plan §4.2): arrays row-major, `a[i,j]` is
  `a[i][j]`; records packed; variant parts overlay at the fixed part's end; 22 above 65535 bytes, 96 above
  64 KB of globals or of one routine's locals; constant indexes are checked (76).
- Name equivalence: each `array`/`record` form is a new type, aliases share it; packed is the same layout.
- Aggregates live in memory (globals, frame slots); assignment is `memory.copy` (decision 12); a value
  parameter is passed by address and copied into the callee frame; a `var` parameter is an address.
- `with` (several records, nested, array elements with the index evaluated once, shadowing locals).
- Not in scope: strings (#37), `{$R+}`; a function result of aggregate type is 34, as the corpus says.
- New TP error numbers needed in `diag.rs`: 22, 34, 44, 75, 93, 96, 121 (and check 54, 39, 40).
- Not tested: `for a[i] := ...` (TP5 accepts it).
