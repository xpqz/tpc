### TP5 findings

1. Negative zero does not exist: `Int(-0.25):0:1` prints `0.0`. `fmt_real` must print `-0` as `0`.
2. Exact decimal ties round away from zero below magnitude 8 (`0.5:0:0` 1, `2.5` 3, `4.25:0:1` 4.3, `6.25` 6.3) but not
   above: `8.5:0:0` gives 8, `9.5` 9, `10.5` 10, `12.5` 13, `1234.5` 1234, `99999.5` 99999, `12.375:0:2` 12.37,
   `24.75:0:1` 24.7, `123456.25:0:1` 123456.2, `10.5:6` (scientific) `1.0E+01`. It is a property of TP5's digit
   generation, not a rule. f64 with exact decimal expansion (`toFixed`/`toExponential`, ties away) is the chosen
   behaviour; ties of magnitude 8 and above are not used by any test (433 of 450 probed cases kept; the 17 dropped are
   those ties and `1.0E30` with decimals, where TP5 prints 11 significant digits then zeros). The lead should add a
   `docs/deviations.md` entry.
3. Write forms: `x:w` scientific with `clamp(w - 7, 1, 10)` fraction digits and a sign column (`" 1.2E+03"`), default and
   `w >= 17` ten digits, `x:w:d` fixed right-justified, `d = 0` has no point, a result longer than `w` is not cut.
   `Write(i:2:1)` for an Integer is Error 89; a Real or non-integer width is Error 38.
4. `1 / 0` as a constant expression is compile Error 140 (dropped, not in scope). `1.5E;` and `1.5E+;` compile (dropped).
5. `Round`/`Trunc` without argument 88, with two arguments 89, with a String 79; `Int`, `Frac` take Integer or Real
   (`Int(3):0:1` fine). `Trunc` and `Round` give LongInt (`i := Round(100.5)` accepted).
6. Division by zero (`6 / (k - 0)`, `Real / 0.0` variable, inside nested calls) is runtime error 200 after earlier output.
7. TP5 reports an error at the line of the token after an incomplete statement when no `;` follows; the checker unit
   test ends every body with `;` so all expected lines are 4.

### Interface fixed by the tests

`host/fmt_real.js` (ESM, counted as `.js`) exports `formatReal(x, width, decimals) -> string` (`-1` for an absent
width or decimals, as passed by `Write(x)` and `Write(x:w)`) and `fmtReal(memory, x, width, decimals, ptr) -> len`,
which `tests/run.mjs` wires as `host.fmt_real`. The compiler imports `host.fmt_real` only in modules that use it (the
no-Real hello-world must not grow).

### Changes

- `compiler/src/types.rs` (+25): `Ty::REAL` (index 10, `Type::Real`, 8 bytes, in memory like a string). `binary`: with a
  Real operand `+ - * /` give Real, comparisons Boolean, other operators 41, non-numeric operands 26; `/` on two integers
  is Real. `unary`: `Round`/`Trunc` give LongInt, `Sqrt`/`Int`/`Frac` Real (non-numeric argument 79), `- Abs Sqr` of a
  Real give Real.
- `compiler/src/ast.rs`, `parse.rs` (+14): `Op::{Slash, Round, Trunc, Sqrt, Int, Frac}`, `Kind::{RealLit, IntToReal}`,
  `Fmt(value, width, decimals)`; the parser accepts real literals, `/` and the second `:`.
- `compiler/src/check.rs` (+72): `Real`, `Pi` and the five intrinsics are predeclared; `intrinsic_op` replaces the
  `(2..=8)` ranges; `coerce_real` makes the `IntToReal` node (a literal becomes a `RealLit`) for assignments, arguments,
  mixed operands, `/` and the real intrinsics; Real constants (`const C = 0.5`, `-1.25`, `Half + 0.25`) are folded;
  `Write` takes Real values and `:d`, which is error 89 for a non-Real; Real function results use the hidden result
  pointer. `Dispose(PI(g))`: a type cast of a variable is a variable for `bad_var_arg` (5 lines; needed by
  `pointer_generic_pointer_assignments`).
- `compiler/src/codegen.rs` (+161): Real values are f64 on the WASM stack (`Gen::real`), stored and passed in memory:
  variables, value parameters (the callee copies the 8 bytes, as for aggregates) and function results (hidden result
  pointer) reuse the string/aggregate machinery, so all WASM signatures stay i32. `Slash` calls `RDIV`, a defined helper
  that raises runtime error 200 for a zero divisor. `Round` is `trunc(x) + trunc(2 * frac(x))` (half away from zero);
  `Trunc` is `i32.trunc_sat_f64_s`. `Write` of a Real calls `host.fmt_real` into a 512-byte frame temporary, then
  `host.write`. The `fmt_real` import and `RDIV` exist only when some node has type Real; later function indices
  shift by `Layout::shift`.
- `host/fmt_real.js` (23 counted lines): `formatReal` and `fmtReal`; `tests/run.mjs` imports it as `host.fmt_real`.
- `docs/deviations.md` D14, D15; `docs/design/ast.md`, `docs/abi.md` updated.
- `tests/{lang,abi,rt,neg}/PENDING`: 24 + 5 + 1 + 26 removed (the target lists). `pointers.rs`, `sets.rs`: `NEG_REAL` and
  its stripped test removed, the programs run unstripped from `NEG` (approved).
