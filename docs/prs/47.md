## Summary

The code is correct and consistently formatted. What makes it hard to learn from:

1. **Magic numbers for TP error codes (140 sites) and intrinsic ids (0..29).** A reader sees
   `Err(self.err(86))` and `s.val >= 26`, and must look up a table.
2. **Giant functions with one idea per match arm**: `check::expr` (232 lines), `check::stmt`
   (161), `check::routine` (150), `check::spec` (105), `codegen::stmt` (151), `codegen::pass`
   (98), `codegen::body` (88), `parse::type_spec` (96).
3. **Tuple and positional soup**: `Types::ord()` returns `(lo, hi, size, signed)` and callers
   write `.2`/`.3` or `(_, _, 1, true)`; `Sec(count, bytes)` with `.0`/`.1`; `List(start, len)`;
   `Routine` keeps `params`, `byref`, `names` as three parallel `Vec`s.
4. **Raw opcode hex literals** in codegen (about 25 distinct, some duplicating named consts).
5. **Unexplained techniques**: static links, frame layout, `Local`->`Frame` promotion
   (`taken`), hidden result pointer, string and set temporaries, the routine worklist, the
   re-generate-until-stable loop, set bit layout, narrowing, desugaring of `Inc/Dec/Str/Val/
   New/...` into assignments to helper calls.
6. Missing module docs in `lib.rs`, `lex.rs`, `diag.rs`, `driver.rs`, `codegen.rs` (too thin),
   `check.rs` (one line), `runtime/system.pas`.

## Suggested order (each step keeps `make test` green)

1. Module docs, comments, renames (L1, D16, C10, C13, S1, S3, S4, and all doc rows). No
   logic change, 0 counted lines.
2. Named error codes (D1) and the `Intrinsic` and `Helper` enums (T2, T3). Largest gain
   for a first-time reader.
3. Struct-for-tuple changes (A1, A3, T1, T8, T10, W1, X1, X4).
4. Function splits in order of reading: lexer (L2, L4), parser (P2-P8), checker (D2-D4,
   D10), codegen (C3, C6, C8, C9).
5. Opcode table (C1, W3, C15-C17).
6. C2 (always-present `fmt_real` and `rdiv`). **This changes emitted modules**: size and
   `tests/dce.rs` expectations must be checked; needs the lead's decision. T9 (payload per
   `SymKind`) also needs a decision: wide diff, modest gain.
