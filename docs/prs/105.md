### Design the tests pin

Pure ES modules in `vscode/src/` that never import `vscode`; `extension.cjs` passes the `vscode` API
object into `src/extension.mjs` (injection), so the glue stays thin.

| Module | Interface |
|---|---|
| `latin1.mjs` | `encodeLatin1(string)` one byte per UTF-16 unit (above 255 gives `?`), `decodeLatin1(bytes)` |
| `positions.mjs` | `splitLines(text)`, `errorRange(lines, line, col)` gives zero-based `{line,start,end}`; col is the compiler's 1-based byte column (`lex.rs`: `pos - line_start + 1`), identical to the UTF-16 offset because buffers are sent one byte per unit; line 0 gives the first position |
| `sources.mjs` | `selectSources({mainName, diskNames, readDisk, buffers})` gives `Map name -> bytes` of the `.pas`/`.inc` files, unsaved buffers beating disk files |
| `compiler_service.mjs` | `CompilerService(module)`, `CompilerService.fromFile(path)`, `compile(mainName, bytes, files)` gives `{ok, wasm}`, `{ok:false, error:{code,line,col,file,message}}` or `{ok:false, internal}`; fresh instance per compile; `error.file` is the key of `files` as given |
| `report.mjs` | `buildReport(result, mainName, linesOf)` gives `[{file, message: "Error N: text", range}]` |
| `scheduler.mjs` | `debouncer(delayMs, run)` with `schedule(key)` and `cancel(key)` |
| `locate.mjs` | `compilerPath(setting, extensionDir)` |

Planned counted change: `err_message_ptr()` / `err_message_len()` in `compiler/src/ffi.rs`, over a
`diag::text(code)` shared with `render`. Planned non-source change: `host/package.json`
(`{"type":"module"}`), because the VS Code 1.90 extension host (Node 20.9) has no module-syntax
detection and would load `host/compiler.js` as CommonJS.
