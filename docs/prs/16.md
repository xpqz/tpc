# #16 Lexer

Branch: `16-lexer`. Stage 1 (RED).

## API (`compiler/src/lex.rs`)

```rust
pub fn lex(src: &[u8]) -> Result<Vec<Tok>, LexErr>;
pub struct Tok { pub kind: Tk, pub line: u32, pub col: u32,
                 pub text: Vec<u8>, pub int: i64, pub real: f64 }
pub struct LexErr { pub num: u16, pub line: u32, pub col: u32 }
pub enum Tk { Ident, IntLit, RealLit, StrLit, Directive, Eof,
              /* one variant per reserved word: And .. Xor, plus Absolute External Forward Interrupt */
              /* Plus Minus Star Slash Eq Lt Gt Le Ge Ne Assign LParen RParen LBrack RBrack
                 Dot DotDot Comma Semi Colon Caret At */ }
```

Contract (the tests pin it):
- The vector always ends with one `Eof` token positioned just past the last byte.
- Lines and columns are 1-based; columns count bytes, a tab is one column; `\n` ends a line,
  `\r` is whitespace. A token's position is its first byte. A directive's position is its
  opening brace.
- `Ident`: `text` is the name uppercased (`_`, letters, digits; digits not first). Keywords
  are matched case-insensitively and carry no payload. The keyword set is the TP5 reserved
  words except `object` (5.5 only), plus the directive words `absolute`, `external`,
  `forward`, `interrupt`. Everything else (`integer`, `true`, `far`, ...) is an `Ident`.
- `IntLit`: `int` holds the value. Decimal up to 2147483647; `$hex` up to `$FFFFFFFF`, whose
  value is the unsigned pattern 4294967295 (the checker reinterprets it as LongInt -1).
  Beyond that, or `$` with no hex digit: error 7 at the number's first byte.
- `RealLit`: `real` holds the value. Digits `.` digits, and/or an exponent `E[+-]digits`.
  `digits.` not followed by a digit is `IntLit` then `Dot` (`1..2` is `IntLit DotDot IntLit`).
  Missing exponent digits, or a value that overflows f64: error 6.
- `StrLit`: `text` holds the bytes (case preserved). Pieces are `'...'` (`''` is a quote),
  `#dec`, `#$hex` (0..255, else error 76; no digits: error 7) and `^X` (X xor 64, `@`..`_`
  and `a`..`z`). Pieces written with no whitespace between them form one token. A `^` starts
  a control character only directly after a piece; elsewhere it is `Caret`. A standalone
  `^A` is therefore not a string (not supported; recorded as a limitation).
  A quote with no closing quote before end of line or input: error 8.
- `Directive`: `{$...}` and `(*$...*)`; `text` is the body after `$`, case and spaces kept.
- Comments `{ }` and `(* *)` are skipped, do not nest, and either opener is inert inside the
  other. Unterminated comment or directive: error 10.
- `(.` and `.)` produce `LBrack` and `RBrack`.
- Any other byte (including `}` outside a comment, `"`, `!`, non-ASCII): error 5.
- Error position is the first byte of the offending token (opening quote, brace, `$`, `#`).
- Numbers 76 (constant out of range, `#256`) and 5 for invalid characters are my choices
  where docs/tp-errors.md gives no lexical mapping; flag if you disagree.

## Tests (`compiler/tests/lex_*.rs`, helpers in `compiler/tests/lex_util/mod.rs`)

79 tests. `lex_util` helpers require a trailing `Eof` and a successful result (`toks`,
`kinds`, `one`, `int`, `real`, `string`) or an error (`err`), so a stub that returns an empty
vector or `Ok` fails every test on behaviour.

- `lex_tokens.rs` (17): every reserved word in lower, upper and alternating case; ident
  uppercasing and case equality; keyword prefixes/suffixes and unreserved names are idents;
  every operator, longest match, `(.`/`.)`, `(*` vs `( *`, caret dereference, a program,
  adjacency, invalid chars (error 5 with columns), empty and whitespace-only input.
- `lex_numbers.rs` (16): decimal and hex values, LongInt boundary (2147483647 ok,
  2147483648 error 7), `$FFFFFFFF` ok, `$100000000` error 7, `$` alone, reals (fractions,
  exponents, signs of exponent, big and tiny), exponent overflow error 6, missing exponent
  digits error 6, `1..2`, `1.`, `1.x`, positions.
- `lex_strings.rs` (17): quotes, empty, `''` escape, `#dec`/`#$hex`, range error 76, no-digit
  error 7, `^` control chars, adjacent pieces (`'a'#13#10'b'`), whitespace splits tokens,
  high/control bytes, long strings, unterminated (error 8, including at newline, CRLF,
  after `#65`), positions.
- `lex_comments.rs` (17): both comment forms, no nesting, inert openers inside each other,
  stray `}` (5), comments at EOF, unterminated (10, position), directives (`{$R+}`,
  `(*$R-*)`, body case/space preserved, `{ $R}` is not one), unterminated directive.
- `lex_positions.rs` (12): columns, lines, tabs, CRLF, blank lines, multi-char tokens,
  after comments and strings, Eof position, error positions, 5000 lines.
