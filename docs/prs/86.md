## Tests (written first, expected output from `tools/tp5.sh`)

Probed with TP 5.0: `RandSeed: LongInt`, zero at program start. Each draw sets
`RandSeed := RandSeed * 134775813 + 1` (mod 2^32). `Random(n)` is the high word of the new
seed mod n (0 for n = 0, seed still advances); `Random` is the new seed as unsigned / 2^32.
`Random(n)` takes any integer type; Real, Boolean arguments are error 38; constants outside
0..65535 are error 76.
