### Design decisions

- Guest console output (no Crt) goes to the screen in the nested Node run, not to stdout, to
  match the browser; the draft shared the runner's sink.
- Files for a run come from the IDE's file system in the `{ run }` message, so the page needs
  no Map of its own; localStorage is read only at load.
- A program that ends without closing a file it wrote does not save it (no close, no hook).
- `{ error }` from the program Worker (a host error) is shown in the status line and returns -1
  to the IDE.
