# #82 Browser console output staircases without Crt

Branch: 82-browser-console-output-staircases-without-crt

## Decision

A program without Crt that does WriteLn then Write continued on the next row at the column
where the previous line ended: System writes LF only for WriteLn on the console, and the
teletype in `host/screen.js` treated LF as "down, keep the column".

Options: System writing CR LF to the console, or the teletype treating LF as newline to
column 1. System's LF-only console output is what the Node runner prints (the corpus `.out`
files are LF), so changing System would change Node output or need a host switch. The teletype
change is one line, line-neutral, touches no Node path, and matches a terminal in cooked
mode (LF as newline). A lone LF no longer has a "down, keep column" use on this screen; Crt
writes through the screen import, not `print`. Chosen: the teletype.
