## Changes

- `compiler/src/symbols.rs` (new): `Symbols` owns the symbol vector, scope stack, `region_start`
  (was `first_user_scope`), `data_end`, routine stack, `next_local`, `local_bytes`. API:
  `new` (declares the predefined names), `bind_system_names`, `start_user_region`,
  `in_system_region`, `declare`, `lookup`, `symbol`, `lookup_symbol`, `lookup_in_region`,
  `declared_since`, `symbol_count`, `into_symbols`, `depth`, `is_nested`, `current_routine`,
  `is_being_checked`, `enter_routine`, `leave_routine`, `next_local`, `data_end`,
  `global_variable`, `local_variable`, `parameter`, `declare_result`, `capture`, `place_frame`;
  free function `name_of`. Also moved here: `Helper`, `PREDEFINED`, `MAX_DATA`, `GLOBALS`,
  `STATIC_LINK_BYTES`. Errors are `SymbolError::{AlreadyDeclared, TooManyVariables}` and
  `MissingSystemName`. Module doc explains the scope and frame techniques and the unit design.
- `compiler/src/check.rs`: `Cx` holds `symbols: Symbols`; `declare` wraps `Symbols::declare` and
  `symbol_error` maps a `SymbolError` to errors 4 and 96; `bind_system_names` keeps the line-0
  diagnostics and the undefined-forward check, stores the helpers. Call sites use `self.symbols`.
- `compiler/src/codegen.rs`: imports `Helper` from `symbols`; doc refers to `symbols::GLOBALS`.
- `compiler/src/lib.rs`: `pub mod symbols`, pipeline doc.
- `tools/budget.txt`: `symbols.rs` under "Types, symbols, frame layout".
- `docs/design/ast.md`: symbols section describes the module, the dependency rule and the unit
  design; stale `taken` renamed `needs_frame_slot`.
- `CLAUDE.md`: "What belongs in which file", one line per compiler source file.

Unit design (documented, not implemented): a unit is a region on the same stack with an
`interface_end`; `uses` re-pushes interface entries; `U.X` scans the interface part of `U`'s
region; System is the first region.

## Design decisions and notes

- `Sym`, `Symbol`, `SymKind`, `Routine` stay in `types.rs` (shared with codegen); moving the
  records is a separate step and was not needed for the dependency rule.
- `place_frame` takes the `Routine` and `Types` as arguments so `Symbols` does not own routines.
- Unit behaviour is not implemented; the design is in the module doc and `ast.md`.
