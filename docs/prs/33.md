## Method

- Every `.out` and `.err` was produced by `tools/tp5.sh` (real TP 5.0 under DOSBox-X) on the committed
  `.pas`; none is hand-written; fpc was not used. `.err` is `N LINE`. A generator script in `tmp/`
  (git-ignored) ran four programs in parallel, wrote `.out` (raw output) or `.err`, and the whole set was
  re-run once at the end: no differences.
- Scope: enums, subranges, arrays, records, `with`, aggregate parameters, strings. No Real, pointers, sets,
  files, typed constants, `{$R+}`. Record layouts used only where TP5 packs without padding (D7).
- No NUL or byte > 127 appears in any `.out` (string comparison with such bytes prints only Booleans).
- Counts: tests/lang 117 new, tests/abi 15 new, tests/neg 81 new.
- Already passing with the current compiler, therefore not in PENDING: lang `string_write_char_with_width`;
  neg `char_plus_char_assign_to_char`, `string_assign_to_integer`, `string_literal_to_char`, `type_unknown_in_var`.
  All other new programs are listed in the PENDING files.
- PENDING after this change: lang 116, abi 15, neg 79 lines (neg includes the 2 from before).
- `make test` passes; `make check` passes.

## TP5 findings and surprises

Names and syntax
- Identifiers are case-insensitive and the program name shares the global scope: `type R` with `var r`
  is Error 4; `program N` with `var n` is Error 4. The first drafts of about 40 programs hit this; negatives use
  the program name `NegTest`.
- `Low` and `High` do not exist in TP5.0 (Error 3, `neg/enum_low_high_unavailable`). `In` is reserved.
- `String[n]`, `array[..]` and `packed` types cannot appear inline in parameter lists, function result types or
  `SizeOf`: parameters and results need a type identifier (`String[n]` parameter: Error 89; `String[n]` result: Error 85; inline `array` parameter: Error 12; array or record result: Error 34). `String[0]`
  and `String[256]` are Error 25. A non-constant size is Error 133.
- Indexing a string constant, a parenthesised expression or a function call (`Name(i)[1]`, `(a+b)[2]`) is Error 121/89.
- A function name used on the right of its own assignment is a recursive call: `F := F + 'x'` is Error 88.
- Variant labels are not checked: duplicate labels and a label of the wrong type are accepted (probed, dropped).

Types
- Identical anonymous types are distinct: `var b: String[5]` passed to `var s: S5` is Error 26, `u := p` between
  `packed array` and unpacked array types is Error 26, and so are two records with identical fields.
- A constant index past `String[n]` is Error 76 (`names[3][7]` on `String[6]`).
- Subrange sizes: smallest predefined type, as in docs/decisions.md (integer typing) (`0..256` and `-129..0` are 2 bytes,
  `0..65536` is 4, `1000..1000` is 2, `100..200` is 1). Enums are 1 byte; records are packed.
- Enum `Write` is Error 64; `for i: Integer := EnumA to EnumB` is Error 26; case labels of another enum are Error 74.
- `array[Integer]` is Error 22 (structure too large); `a[1, 2]` on a 1-D array is Error 93.

String semantics (oracle outputs)
- `String` is `String[255]`; `SizeOf(String)` is 256. Concatenation beyond 255 truncates silently.
- `s[0] := Chr(n)` changes the length; characters beyond the old length are readable and writable.
- Comparison is byte-wise lexicographic, then by length; `#0` is greater than ''. Char and String compare freely.
- `Copy(s, i, n)`: `i` beyond length gives '' ; `i = 0` and negative `i` behave as `i = 1` (`Copy(s,-1,3)` = 'abc');
  negative `n` gives ''; `n` past the end clips.
- `Delete(s, i, n)`: `i = 0` removes `n - 1` characters (`Delete(s,0,3)` on 'abcdefgh' gives 'cdefgh'),
  negative `i` or negative `n` is a no-op, `i` past the end is a no-op.
- `Insert(src, s, i)`: `i <= 0` inserts at the front; `i` past the end appends; the result is truncated to the
  capacity of `s` (`String[8]`: 'abcdefXY').
- `Pos('', s)` is 1 for non-empty and empty `s` (`Pos('', '')` is 1). `Pos` takes Char and String arguments.
- `Write(s:w)` right-aligns when `w > Length(s)`, otherwise prints `s` unpadded; `w = 0` and `w = 1` print `s`.
  An empty string with a width prints blanks.
- `s := c + d` (Char + Char) is a String; Concat accepts one argument.

Tooling
- `tools/tp5.sh` fails on output containing bytes above 127 (`tr: Illegal byte sequence`, exit 1, output cut off)
  under a UTF-8 locale; running it with `LC_ALL=C` works. The script was not changed (outside scope). This
  corpus avoids such output, so the oracle makes no difference here.
