# #67 IDE tooling: oracle, key chords, host contract

Branch: 67-ide-tooling-oracle-key-chords-host-contract. Probes, small tooling and design; no
change in `compiler/src`, `runtime/` or `host/`. Decisions 40 to 44 in `docs/decisions.md` are
the proposals; this file records what was run and found.

## 1. IDE oracle pattern (decision 40)

- `tests/lang/crt_ide_oracle_pattern_editor_unit_with_host_stub.{pas,keys,out}` and its directory
  `EDITOR.PAS`, `IDEHOST.PAS`: main program `uses Crt, Editor`; `Editor` is a toy line editor
  (typing, Backspace, Enter, cursor keys, `^Y`, `^K b` / `^K k` with `^B`/`^K` as second keys,
  F9, Ctrl-F9, Alt-X, menu bar, status line, a log row); `IdeHost` is the stand-in with the
  planned interface. The keys: type `begin`, a line `ERROR`, `end.`, F9 (error 3 at 2:1, the
  cursor jumps), `^K b`, `^Y`, F9 (compiles), Ctrl-F9 (exit code 2), cursor keys, `^K ^K`,
  `^K z` (unknown), Alt-X. The log row of the dump shows every status message:
  `Ready; Error 3 in P.PAS; Compiled; Compiled; Exit code 2; Unknown ^K command;`, then the
  cursor, `exit 0` and the attributes. Alt-X leaves the screen uncleared.
- `.out` made by `tools/tp5.sh` (real TP 5.0), identical output from this compiler through
  `tests/run.mjs` (and so through the corpus tests: `crt_unit.rs`'s count of `crt_*` programs
  went 43 to 45 for this and the chord test).
- `tools/tp5.sh` gained `NAME.dirs` (shared directories copied first); tests in
  `tests/tools/tp5_test.sh` with fixtures `dirs_use` (own stub wins) and `dirs_only`.
- `tests/ide/draft/canned.mjs`: the canned compiler for the runner side, same two rules.

## 2. Key chords (decision 41)

- `tools/crt/KEYS.TBL`: 135 keys (was 33): Table C.2, Appendix C, page 424 of the Reference
  Guide (Table C.3, page 426, has the scan codes of the letters), see decision 41.
  `tools/tp5.sh`'s header lists the names. `tests/keys.mjs` reads the table, so it is unchanged.
- `tests/lang/crt_readkey_control_letters_and_extended_chords.{pas,keys,out}`: 30 keys
  (`^A ^K ^Q ^Y ^Z`, Alt, Shift, Ctrl F-keys, Ctrl-cursor keys, Shift-Tab, Ctrl-PrtSc, Esc);
  `.out` from TP 5.0 (`c1 c11 c17 c25 c26 c2 c26 x45 x30 x120 x131 x130 x84 x94 ...`),
  identical from this compiler. Alt-X is `x45`, Ctrl-F9 `x102`, Alt-F10 `x113`, matching the table.
- Probe `tests/host/browser/chords.mjs` (not in `make test-browser`; `BROWSER=chrome|firefox`):
  77 chords (Ctrl+A..Z, Alt+X/A/1, F1..F10 plain/Shift/Ctrl/Alt, Shift/Ctrl+Tab, Ctrl+cursor
  keys) injected into a running page; records what a capturing `keydown` listener sees and
  what today's `keyBytes` makes of it. Chrome 157 and Firefox 160: 77/77 received, identical
  tables (`key`, `code`, modifiers correct), tab count unchanged. Today's mapping: Ctrl+letter
  right (1..26); Shift/Ctrl/Alt+F1..F10 = plain F-key bytes; Alt+letter = the letter; Ctrl+Left
  etc. = plain cursor key; Shift-Tab = Tab (all wrong against Table C.2).
  `tests/host/browser/chrome.mjs` got `modifiers` support in `key` (both backends) and
  `page.contexts()`.
- Limit of the probe: both drivers inject below the browser's shortcut handling, so
  Ctrl+W/N/T are "received" although a user's browser would keep them. No real keyboard was
  available (headed OS-level input would need accessibility permission and focus). The
  reserved-key claims in decision 41 are from documented browser behaviour and unverified.
- Draft `tests/ide/draft/key_bytes.js` (38 lines) with `key_bytes_test.mjs`: 122 table keys as
  events (Alt-digits and Ctrl-PrtSc excluded on purpose), negative cases, AltGr/Option typing.

## 3. Host contract (decision 42)

Drafts and tests in `tests/ide/draft/`: `compiler.js` (42 counted lines), `ide.js` (25),
`node_ide.mjs` (test glue: loads compiler.wasm, nested run), `canned.mjs`, `draft_test.mjs`
(9 tests, real `tp5c.wasm`), `oracle/` (programs and `.out` from TP 5.0 for the compile errors
and the Crt run). Findings while building it: `err_file` numbers follow first registration
order and registered files stay registered, so the wrapper keeps the name list; `alloc` holds
name and source in one buffer; the program's Crt does not read the cursor, so the run must
start on a cleared screen. The browser pieces (Worker, page, `Vfs` hook) are sketched in the
decision only; they were not built or run.

## 5. TP 5.0 limits (decision 44)

`tests/ide/limits/`: `getmem_largest_block`, `index_arithmetic_above_32767`,
`longint_index_above_32767` (run by `compiler/tests/ide_tooling.rs` against this compiler, all
equal to TP's output) and `tp_only/*` (six records of TP-only behaviour: error 22, 76, 96,
the Word truncation of `GetMem`, error 201 under `{$R+}`, a 65535-byte global accepted).

## Gaps in this compiler found on the way (not fixed, outside scope)

`Move`, `FillChar` and `Halt` are missing (Halt is listed as supported in `docs/subset.md`);
untyped `var` parameters give Error 200; `Bytes(P^)[0] := 1` (cast then index) gives Error 85;
`GetMem` takes a LongInt (TP: Word).
