## Tool design

- Pre-filter is text-only on a tokenised copy (strings, comments and directives blanked) and
  is re-applied to every file on each run, so changing it reclassifies the cache.
- Results cache key is path plus content hash; `--redo CLASS` repeats a class.
- At most 4 runs in parallel; no process is signalled by the tool except node on its own
  timeout. `tp5.sh` owns the DOSBox lifecycle.
- Known limits: the pre-filter's word scan matches identifiers anywhere (a variable called
  `Port` filters the file); only the first compiler error of a file is seen.
