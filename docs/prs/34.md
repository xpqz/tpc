## Intended behaviour (GREEN, decisions 11 and 14)

- `runtime/system.pas`: a declaration part, embedded with `include_bytes!`, lexed with every token
  at line 0, parsed ahead of the program's declarations into the same AST, checked in an outer
  scope at routine depth 1 (`Cx::user` is set after it, so programs redeclare its names). Starts
  with `Lo`, `Hi`, `UpCase`, the variable `ExitCode` (real TP5 names, so the oracle covers them)
  and the helper `AbsLong`.
- Placeholder implicit helper: `Abs` calls System's `AbsLong(LongInt): LongInt` through a routine
  handle (`Info`), looked up once right after System is checked; the inline select code in
  `Gen::unary` goes away. A System without it is error 3 at line 0.
- Diagnostics from System text carry line 0; a parse end-of-file (10) keeps line 0 instead of being
  moved to the user's last line. User lines are unaffected by the size of System.
- Codegen: `Layout` becomes mutable state; routine WASM indices are assigned on first reference
  (main first, then every address-taken routine, then a worklist), bodies are emitted in index
  order; literal addresses are assigned on first use. Globals stay laid out before literals.
- `compile_with(system, src)` is the test hook (`compile(src)` uses the embedded file). In this RED
  commit it ignores `system` and exists only so the tests compile.
- Deviation to record at GREEN (`docs/deviations.md`): System helper names (`AbsLong`) are visible,
  so a program using an undeclared identifier of that name compiles instead of error 3. Deliberately
  not tested.
- Not covered: a procedural type that only an unused routine mentions still gets a WASM type (the
  type section is built from all checked types); noted for the lead, no test.

## Method

Every `.out` and `.err` under `compiler/tests/fixtures/system/{lang,neg}` came from `tools/tp5.sh`
on the committed `.pas`. `hook/synthetic.out` came from `tools/tp5.sh` on one source made of the
`program` line, `synthetic.sys` and the rest of `synthetic.pas`. Tests that use a synthetic System
whose behaviour has no TP5 counterpart (the helper returning 777, to make the call observable) say
so. Probes lived in `tmp/p34/` (git-ignored). TP5 findings: `var Length: Integer;` and
`var ExitCode: LongInt;` are accepted; redeclaring `Lo`/`UpCase` as functions, `Hi`/`ExitCode` as
constants, `Lo`/`UpCase` as types are accepted; `Lo(1,2)` is 89 and `Lo := 3`/`Lo` alone are 88
(builtin-only, so not used: our `Lo` is an ordinary routine); `Lo(True)` is 38 and `UpCase(65)` is
106 (builtin-only, not used).
