### Design the tests pin (new modules in `vscode/src/`, none imports `vscode`)

| Module | Interface |
|---|---|
| `terminal_text.mjs` | `createOutputDecoder()` returns `decode(bytes) -> string`: bytes below 128 as they are, LF becomes CR LF unless the previous byte (also across chunks) was CR, bytes from 128 CP437 to Unicode. `inputBytes(data) -> number[]`: terminal input to ReadKey bytes (`\r` 13, DEL and BS 8, ASCII as is, CP437 characters to their byte, arrows and Delete to `0, code`, other escape sequences dropped, lone Esc 27) |
| `run_session.mjs` | `startRun({wasm, directory, writeFiles, onOutput}) -> {sendKeys(bytes), stop(), ended}`; `ended` resolves `{kind:"exit",code}`, `{kind:"stopped"}` or `{kind:"crashed",message}` after the final text went to `onOutput`: `\r\nexit code N\r\n`, `stopped`, `error: ...`. `usesCrt(wasm)` (imports `screen`), `CRT_MESSAGE`. The worker is `src/program_worker.mjs`, which uses `Host` directly. The directory's regular 8.3 files are the snapshot; with `writeFiles` the host's `onWritten`/`onErased` go to disk, never through a symbolic link, only under 8.3 names |
| `run_terminal.mjs` | `createRunPty(EventEmitter, {wasm, directory, writeFiles})` returns a Pseudoterminal (`onDidWrite`, `onDidClose`, `open`, `close`, `handleInput`) plus `stop()` and `running`; Ctrl+C or `stop()` ends the run, after the end "Press any key to close the terminal." and the next key fires `onDidClose` |
| `extension.mjs` | commands `tp5.compile`, `tp5.run`, `tp5.stop`; the error message of a failed compile is `main.pas(3): Error 3: Unknown identifier` |

Decisions pinned here: F9 compile and Ctrl+F9 run, both `when editorLangId == tp5pascal`. F9 is
"toggle breakpoint" in VS Code, which a Pascal file without a debugger does not use; an extension
keybinding overrides a default one. Ctrl+F9 has no default binding. The host prints
`Runtime error NNN` (no address: docs/abi.md), so the terminal shows that line followed by
`exit code NNN`; "Runtime error N at ..." is not available without a host change.
