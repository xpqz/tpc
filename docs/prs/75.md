# #75 IDE Buffer

Branch: 75-ide-buffer (worktree `worktrees/75-ide-buffer`).

## Stage 1: RED

### Interface the tests fix (unit `Buffer`, `ide/buffer.pas`)

Decision 44's representation (`^array[0..65520] of Char` from `GetMem`, `LongInt` positions, gap
moved with loops). Positions are 0-based, lines and columns 1-based, lines separated by
`LineBreak` (#10). TP 5.0 has no `{$X+}`: a function call cannot be a statement (error 122), so
every operation the IDE calls for effect is a procedure.

- `MaxText = 65521`, `LineBreak`, `LoadTooLarge = -1`.
- `Clear`, `TextLength`, `Cursor`, `CharAt(Pos)` (`#0` outside the text), `IsFull`.
- `SetCursor(Pos)` (clamped), `MoveLeft`, `MoveRight`, `MoveUp`, `MoveDown` (keep the wanted
  column across a run of vertical moves; every horizontal move or edit forgets it),
  `MoveToLineStart`, `MoveToLineEnd`.
- `InsertChar(Ch)` (ignored when full), `DeleteBefore` (Backspace), `DeleteAfter` (Delete).
- `LineCount`, `LineOf(Pos)`, `ColumnOf(Pos)`, `LineStartPos(Pos)`, `LineEndPos(Pos)`,
  `PosOf(Line, Column)` (line past the last is the last, column past the end is the end).
- `TextPointer: Pointer`: closes the gap, so the text is `TextLength` bytes at the pointer; this
  is the `Text`/`Len` of `IdeHost.Compile` (decision 42). Valid until the next edit; the cursor
  is unchanged.
- `Load(Name): Integer`: 0, the `IOResult` of opening (text unchanged), or `LoadTooLarge`
  (text emptied). Every line, the last included, ends with a `LineBreak` in the buffer.
  `Save(Name): Integer`: 0 or an `IOResult`; one `WriteLn` per `LineBreak`.

### Tests (`tests/lang/ide_buffer_*`; each `NAME.dirs` holds `ide`)

Each program has a `NAME.dirs` file (`ide`), so `tools/tp5.sh` copies `ide/` beside it, and
`compiler/tests/driver/mod.rs` merges `ide/` and the fixture directory into the `--dir` of
`tp5c` and `tests/run.mjs`.

- `ide_buffer_insert_delete_and_cursor_moves`: empty buffer (delete at both ends, `CharAt`
  outside), typing, insert in the middle, Backspace, Delete, no-ops at both ends, `SetCursor`
  clamping, `TextPointer` contents and checksum then editing after it, deletes across a line
  break, Backspace past the start.
- `ide_buffer_lines_columns_and_positions`: line/column/start/end for every position -1..len+1 of
  a text with an empty and a one-blank line; `PosOf` with line 0 to 6 and column 0, 6, 12;
  `MoveUp`/`MoveDown` through a short and an empty line (wanted column kept and restored), at the
  first and last line; four scenarios showing typing, Backspace, Delete and horizontal moves
  forget the wanted column; trailing break (empty last line); a text of only breaks.
- `ide_buffer_capacity_and_positions_above_32767`: fills to 65521 (five more characters are
  refused), insert when full, `LineCount` 3277, `LineOf`/`PosOf` around 40000, `CharAt` at 32766
  to 32768, 65520, 65521; cursor, vertical moves and line end at 50000; cursor across 32767;
  gap moves over the whole block (delete at 65000, type at 10 with room for 100 of 150, delete
  3000 from the end and from the start); every-7th-character checksums through `CharAt` and
  through `TextPointer` agree.
- `ide_buffer_load_and_save_text_files` (fixture files `CRLF.TXT`, `NOEOL.TXT`, `EMPTY.TXT`,
  `LONG.TXT`): CRLF file, no final break, empty file, a 300-character line, missing file
  (`IOResult` 2, text unchanged), save then dump the bytes (CRLF, no final break written for an
  unterminated last line), save empty, round trip, a file of exactly 65521 characters (loads, full,
  saves and reloads) and one of 65522 (`LoadTooLarge`, text empty).
- `ide_buffer_agrees_with_a_model_under_random_edits`: 3000 pseudo-random operations applied to
  the buffer and to a plain array; length, cursor, line and column compared after each, all
  characters at the end; prints 0 mismatches, so it also fails if the comparison is vacuous
  (the final length, cursor, line count and checksum come from TP).
- Driver: `compiler/tests/driver/mod.rs` gains `aux_dir` (`NAME.dirs` support, same format as
  `tools/tp5.sh`; a missing shared directory is skipped so each program fails on its own);
  test `shared_directories_are_merged_with_the_aux_directory_and_the_own_unit_wins` in
  `compiler/tests/lang.rs` with fixture `compiler/tests/fixtures/lang/shared_dirs` and
  `compiler/tests/fixtures/shared_units`.

### How the goldens were made

The oracle needs a unit to compile, so `.out` files come from `tools/tp5.sh` running the five
programs against a **draft** `ide/buffer.pas` (295 counted lines, kept at
`tmp/buffer_draft.pas`, not committed). With the draft in place the five outputs from real TP
5.0 are byte-identical to this compiler's (`cargo test --test lang`: 20 passed, which includes
the corpus). The draft was then removed for this commit. I read every `.out` against the intent
(for instance positions, columns and wanted-column results by hand). Fixture notes: a TP-only
limit found on the way, a function call as a statement is error 122 in TP 5.0 (no `{$X+}`).

Oracle times (DOSBox, with other DOSBox instances running): capacity 47 s, load/save 42 s,
random 21 s, others under 1 s. `tools/tp5.sh`'s default timeout is 60 s; the two slow ones
are dominated by moving the gap over 65K characters on an emulated 8086 (a fill alone is 5 s).

### Intended behaviour

As listed under the interface. Line breaks inside the buffer are `LineBreak` only; `Load` strips
CRLF and `Save` writes CRLF (what `WriteLn` writes), so a file round trip is stable.
