# #13 Node test runner and Phase 0 exit test

## Stage 1: RED

### Runner contract (decisions, to be copied into `docs/abi.md` at GREEN)

`node tests/run.mjs prog.wasm [expected.out]`; JS API `export async function run(bytes) -> {stdout, code}`
(`stdout` is a Buffer; importing the module must not run the CLI).

- Module ABI: the module exports `main` (`() -> ()`) and `memory`. Both are required; a missing one is a runner error.
- `host.write(fd, ptr, len)`: fd 1 appended to captured stdout, fd 2 to the runner's stderr, any other fd is a runner error
  ("bad fd N"). Bytes are copied raw from `memory` (no text decoding; 0x80-0xFF intact). `len` 0 is a no-op, `ptr` unchecked then.
  Range outside memory is a runner error ("out of bounds").
- `host.halt(code)`: throws a sentinel; execution stops, output so far is kept, runner exit code is `code`.
- `host.rterror(code)`: appends `Runtime error N\n` to captured stdout (no leading newline, no address), then behaves as `halt(code)`.
  Measured with `fpc -Mtp -v0`: it prints `Runtime error 200 at $addr` to stderr and exits 200. TP5 prints to the console (stdout)
  and the DOS errorlevel is N. Decision: stdout, so `tests/rt/` expectations see it; exit code N as in both.
- All other §4.9 imports (`readkey keypressed readline screen fs_open fs_read fs_write fs_close fmt_real time compile`) are stubs
  throwing `host import X not available in test runner`. An import not in this set (or module not `host`) fails instantiation
  with `unknown import module.name`.
- Exit codes: output matches (or no expected file) -> the program's code (0 normally, N after halt/rterror); output mismatch -> 1;
  runner error -> 2 with `run.mjs: ...` on stderr. Runner errors: usage, unreadable wasm or expected file, `invalid wasm`,
  unknown import, missing export, stub called, wasm trap, bad fd, out-of-bounds write. Known ambiguity: program `halt(2)` and a
  runner error both exit 2; later drivers use the stderr prefix to tell them apart.
- Comparison is byte-exact (no CRLF or trailing-newline normalisation). Pass is silent. Failure prints to stderr `FAIL <wasm>`, a
  line diff (`-` expected-only, `+` actual-only, ` ` common) and `first difference at byte N`.
- Expected file is read before the module runs; missing expected file is exit 2 without running.
