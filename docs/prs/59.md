## Part B: Crt oracle probes (headless DOSBox-X, TP 5.0)

Prototypes: `tools/crt/SCRDUMP.PAS`, `tools/crt/KEYFEED.PAS` (not yet wired into tp5.sh).

1. Screen dump works. A unit reading `Mem[$B800:...]` from an `ExitProc` wrote SCREEN.TXT under
   `-silent -nogui`; chars, attributes, cursor (`Mem[$40:$50]`), `ExitCode`, `ErrorAddr`
   all read. Verified on: ClrScr/GotoXY/TextAttr; 30 lines scrolling (last 25 kept); runtime
   error 200 (dump ran, `exit 200 error 0000:0086`, red cell run reported as `attr 25 1 3 04`).
   TP 5.0 needs `{$F+}` for the exit procedure (no `far` directive).
2. Without `cls` the screen holds the DOS command echo; tp5.sh must clear it first.
3. Under Crt, Write ignores `> RUN.TXT` and ReadLn ignores `< P.IN` (hangs waiting for a key).
4. Keys: Crt uses BIOS INT 16h. Replacing it with an `interrupt` procedure (KEYFEED) fed
   `abc...` plus Enter (45 keys) to `KeyPressed`/`ReadKey`; prefilling the BIOS ring
   (`MemW[$40:$1A..$1E]`) also fed `ReadKey` and `ReadLn` (up to 15 keys). Extended keys need
   a scan code in `Hi(AX)`. DOSBox-X itself has no scripted-typing switch used here.
5. Proposals: decisions 37 (tp5.sh wiring, dump format) and 38 (virtual clock).

Commands: `make check` (pass); ad-hoc probes via a local script in `tmp/probe1` (T1 to T6,
untracked). One T3 probe (ReadLn under Crt with stdin) timed out as predicted.
