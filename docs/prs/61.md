# #61 Phase 6 test corpus

Branch `61-phase-6-test-corpus`. Test files only: nothing under `compiler/src`, `runtime/`, `host/` or the drivers.
`tools/loc.sh` total 8787 / 15000 (Host glue 471 / 500) before and after (delta 0).

## Method

- Every `.out` and `.err` was produced by `tools/tp5.sh` (real TP 5.0 under DOSBox-X) on the committed program, with
  `NAME.keys` beside it where the program reads keys. A Crt `.out` is the program's stdout followed by the screen dump
  (25 rows, `cursor`, `exit`, `attr` runs; decision 37). `rt` outputs drop TP5's ` at XXXX:YYYY.`; `neg` `.err` is `N LINE`.
  Nothing is hand-written; fpc supplied nothing. Each output was read through for plausibility.
- Rules kept: no program waits on a key after its keys run out (every `ReadKey`/`ReadLn` has its keys and each `while KeyPressed`
  loop ends when the script does); no program depends on elapsed time (`Delay` only with small values, never measured);
  no program prints the real clock.
- Counts: `lang` 43 (16 with `.keys`, one with an aux unit directory), `rt` 4 (1 with `.keys`), `neg` 12. All are in the `PENDING`
  lists except three `neg` programs the current compiler already rejects with the TP5 number and line
  (`crt_routine_without_uses_crt`, `crt_constant_without_uses_crt`, `crt_unknown_unit_name_crtt`). New PENDING lines:
  lang 43, rt 4, neg 9.
- Not covered on purpose: `TextMode`, `LastMode`, `WindMin`/`WindMax`, `CheckBreak`, `CheckEof`, `CheckSnow`, `DirectVideo`,
  `AssignCrt` (all exist in TP 5.0's Crt, none is in plan scope); `Halt(n)` and exhausted keys (exit code, not an `.out`
  the lang/rt drivers can express; exhaustion is already tested in `tests/tools/fixtures/tp5/crt_exhausted`).

## TP 5.0 findings (Crt)

- Present in 5.0: ClrScr, ClrEol, InsLine, DelLine, GotoXY, WhereX, WhereY, Window, TextColor, TextBackground, TextAttr,
  HighVideo, LowVideo, NormVideo, Delay, Sound, NoSound, ReadKey, KeyPressed, plus TextMode, LastMode, WindMin, WindMax, CheckBreak,
  CheckEof, CheckSnow, DirectVideo, AssignCrt and the constants BW40..Font8x8, Black..White, Blink (probed together in one program).
- `GotoXY` with an argument outside the current window (0, or past the window, up to 255) is ignored: the cursor stays.
  `Window` with an invalid rectangle (a 0, x2 > 80, y2 > 25, x2 < x1, y2 < y1) is ignored; a one-row and a one-cell window are valid.
  `Window` homes the cursor to the window's origin (1,1).
- `ClrScr`, `ClrEol`, `InsLine` and the blank row of `DelLine` fill with the current TextAttr. They work inside the window only.
- Writing the last cell of the screen (80,25), or of a window, scrolls at once (the cursor is then at column 1 of the last row); a
  program that writes `'Z'` in the window's bottom-right corner finds it one row up.
- Under Crt `Write(#8)` moves left (stops at column 1), `#13` goes to column 1, `#10` down one row (same column), `#7` is silent
  (nothing on the screen), other bytes, including `#9`, `#27`, `#127` and `#128..#255`, are glyphs that advance the cursor.
- `TextBackground(c)` keeps only bits 0..2 of `c`; `TextColor(Green + Blink)` sets bit 7 (blink). `HighVideo` sets
  bit 3 of TextAttr, `LowVideo` clears it, `NormVideo` restores the attribute at program start ($07 here).
- `ReadKey` returns `#0` then the scan code for extended keys; `KeyPressed` stays true between the two. `ReadLn` under Crt echoes
  typed characters, Backspace erases one (nothing at the start of the line), Esc erases the whole line, extended keys are ignored,
  and `String[4]` receives the first four characters of a longer line (all typed characters stay on screen).
  `Read(c)` returns `#13` for Enter.
- `Sound` and `NoSound` change nothing on the screen; `Delay(0)` returns.
