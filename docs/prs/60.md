## What changed

- `tools/tp5.sh`: a `RUN.BAT` (`@echo off`, `cls`, the program line) runs the program, so every
  program starts on a cleared screen and its own command line is not echoed onto it (a plain
  `cls` before `P` left the echo of `P` on row 1; measured). A program whose uses clause names
  Crt (multi-line `uses` handled; same line count as the original) gets `ScrDump, KeyFeed,` in
  front of its first `uses` list, so ScrDump's exit procedure runs last. The script prints
  RUN.TXT, then SCREEN.TXT. Key script `NAME.keys`: whitespace-separated tokens, a name from
  `tools/crt/KEYS.TBL` (any case) or one printable character; `tools/crt/keys.awk` turns it into
  `KEYS.DAT` (one `$AAAA` INT 16h word per line); an unknown token is exit 2. Format documented
  in the script header.
- `tools/crt/SCRDUMP.PAS`: split into small procedures; the `exit` line is now `exit CODE`
  only (the `error SEG:OFS` part is dropped: ErrorAddr is not comparable, decision 37).
- `tools/crt/KEYFEED.PAS`: reads `KEYS.DAT`; a blocking read after the last key calls
  `Halt(255)` (shows as `exit 255` in the dump); `KeyPressed` is false when no key is left (a
  program that waits for a key with `repeat until KeyPressed` and has no keys left hangs until
  `TP5_TIMEOUT`, in the runner until killed).
- `host/screen.js` (new): `Screen` grid, `apply(op, a, b, c)`, `dump(exitCode)`. Ops in
  docs/abi.md section 8: 0 put, 1 scroll up, 2 scroll down, 3 cursor; coordinates 0-based;
  16-bit packed operands. Off-screen cell or unknown op is a `HostError`.
- `host/error.js` (new, 1 line): `HostError` moved out of `runtime.js` (re-exported there) so
  `screen.js` can throw it without a cycle.
- `host/runtime.js`: `Host({ write, input, files, clock, keys })`; `clock` is
  `{ nowMs(), advance(ms) }`, `keys` is `{ available(), next() }`; imports `screen`, `readkey`
  (INT 16h word, `Halt(255)` when none), `keypressed`, `sleep`. `host.screen` is the grid.
- `tests/keys.mjs` (new, not counted): `parseKeys`, `KeyScript`. `tests/run.mjs`: `--keys`,
  `run(..., { keys })`, virtual clock (starts at `TP5_NOW_MS`, else the real local time at start;
  moves only through `sleep`), dump appended to stdout when the module imports `screen`.
- Drivers (`compiler/tests/driver/mod.rs`): pass `NAME.keys` as `--keys`; `check_rt` takes the
  code from the last `Runtime error N` line anywhere in `.out` (a Crt program's dump follows it);
  fake compiler directive `#key`.
- `tools/oracle.sh`: the " at XXXX:YYYY." strip no longer needs the end of the output.
  Crt programs need nothing else: tp5.sh prints stdout plus dump, so `.out` holds both.
- docs/abi.md section 8: op numbering and packing, readkey/keypressed/sleep, dump format,
  runner contract (`--keys`, virtual clock, only `compile` is still a stub).

## Design notes

- The key table is one file (`tools/crt/KEYS.TBL`) read by `keys.awk` and `tests/keys.mjs`,
  so the real TP and the runner cannot disagree on key codes.
- Key script tokens are single characters or names (no quoted strings); `Space` is the space
  key. No comments in key scripts (every printable character is a key).
- `readkey` returns the INT 16h word, so the Pascal Crt (Phase 6) splits extended keys into
  `#0` + scan code itself, as the real Crt does.
- A Crt program that is only reached through a unit that uses Crt (not named in the program's
  own uses clause) is not detected by tp5.sh.
- A program importing `screen` that never draws still prints a dump (blank rows).
