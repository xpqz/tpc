## In-editor tests (`tests/vscode/editor/index.cjs`)

Run in the real VS Code through the real API; expected error numbers/lines come from `tools/tp5.sh`
(`P.PAS(5): Error 85: ";" expected.` for the missing `;`; `U1.PAS(7): Error 3: Unknown identifier.` for the
unit, with the fixture dir form of tp5.sh).

1. activates for a Pascal file (language id `tp5pascal`, extension `xpqz.tp5-pascal` active).
2. `Error 85: ";" expected` as a `tp5` Error diagnostic at line index 4; replacing the text clears it.
3. unit error `Error 3: Unknown identifier` on the unit's own URI at line index 6.
4. `tp5.compile` writes `hello.wasm` (wasm magic); a program with an error writes none.
5. `tp5.run` opens terminal `TP5: hello_run.pas`; the run session (from the exported `runs`) ends.
6. a Crt program stays running with no input and ends after `tp5.stop`.

failed 3 of 7: test 1 (extension id not found), and tests 5 and 6 with
