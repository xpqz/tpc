  `-s`, `s * s` and `s and s` are 41; `WriteLn(s:s)` is 38; `s[1] := 'ab'` and `s[0] := 65` are 26.

- Redeclaring `Length`, `Pos`, `Copy`, `Concat`, `Delete`, `Insert` and `UpCase` is accepted, and

## Intended behaviour (GREEN)

- Types: `String` is `String[255]`, `String[n]` has size n+1 (n constant 1..255, else 25; non-constant 133;
  missing bracket 93), name equivalence as for arrays; `SizeOf(String)` is 256.
- Decision 13: every string-valued expression evaluates into a 256-byte frame temporary; one truncating
  store copies into a `String[n]`; `+`, `Copy`, function results go through it, so aliasing works.
- Helpers (concat, compare, copy, pos, delete, insert) are ordinary Pascal in `runtime/system.pas`, bound by
  routine handle after System is loaded (decision 11); the compiler emits calls and a `CharToStr` coercion.
- Function results of type String use the hidden result pointer (plan §4.4, decision 15).
- New TP error numbers for `diag.rs`: 25, 66, 67, 106 (and check 8, 87, 89, 93, 133).

Open question for the lead (nothing in the tests depends on it): `system_unit.rs` compiles with a System
that holds only `AbsLong` (`HELPER_ONLY`) and expects a missing helper to be error 3 at line 0. If the
string helpers are bound at load like `AbsLong`, those tests need the extra helpers in `HELPER_ONLY`; if
the string helpers are bound only when present (an unbound helper used by a program is an error at that
use), they stay as they are.
