## Stage 2: GREEN

### Changes

- `compiler/src/types.rs`: `Intrinsic::Halt`.
- `compiler/src/symbols.rs`: predefined name `HALT`; `Helper::HostHalt` named `HOSTHALT`.
- `runtime/system.pas`: `procedure HostHalt(code: LongInt); external 'halt';` (decision 29;
  `HostHalt` as `HostWrite`, because `Halt` is predeclared). Header comment lists it.
- `compiler/src/check.rs`: `halt_call` checks 0 or 1 argument (error 89 for more), types the
  argument as Word through `argument_assignable` (38 and 76 as TP) and rewrites the call to
  `Invoke(HostHalt, [code])`, with 0 when there is no argument. `Halt` in an expression is 42
  via the existing intrinsic arms. New `is_designator` decides whether a callee is a value
  or a routine to look up (a non-name, or a name that is a field of an enclosing `with`);
  `call_statement` (#69) and `call_expr` (#71) share it, so a field hides a same-named routine
  in expressions too.
- Tests support: `compiler/tests/driver/mod.rs` `check_halt`, `compiler/tests/lang.rs` test
  `halt_corpus_exits_with_the_halt_code_and_keeps_earlier_output`; the synthetic System text in
  `compiler/tests/system_unit.rs` and `compiler/tests/fixtures/system/hook/synthetic.sys`
  gained the `HostHalt` declaration (every helper must exist in System).

Design decision: no new wasm instruction or codegen path. `halt` throws in the host, so
the call needs no `unreachable` after it; statements after `Halt` are still compiled.
