### Probes (real TP 5.0 under DOSBox-X, scratch dirs in `tmp/`)

| Question | Finding |
|---|---|
| Does DOSBox-X redirect stdin and stdout together? | Yes: `-c "P < P.IN > RUN.TXT"` works. Input with CRLF lines reads correctly with `ReadLn`; `Eof` is true after the last line. |
| Does TPC compile used units from source? | Not by default: `Error 15: File not found (U.TPU)`. `tpc /M P.PAS` (make) compiles `U.PAS` to `U.TPU` and works. `/M` is what `tools/tp5.sh` uses. |
| Error in a unit / include | Reported as `U.PAS(7): Error 3: Unknown identifier.` and `INC.INC(2): Error 3: ...`. The output line is preceded by `NAME(0)` progress words separated by CR, so the grep takes the `NAME.EXT(N): Error` part with `grep -o`. |
| Include inside a statement part | `{$I X}` between `begin` and `end` of the main block gives `Error 118: Include files are not allowed here.` (TP 5.0 restriction). Includes belong in declaration parts. |
| One-digit runtime error | Printed with three digits: `Runtime error 002 at 0000:002F.` (file not found). The runner therefore prints `Runtime error 002` (three digits); `.out` files for codes below 100 contain the padded form. `check_rt` parses `002` as 2. |
| Line endings TP writes to text files | CRLF for `WriteLn`; `Append` continues after the old bytes; nothing is written at `Close` (no ^Z). |
| ^Z on read | In a text file a ^Z byte (26) ends the file: `Eof` is true there, `ReadLn` returns the text before it, `Read(Char)` never returns it, `Eoln` is true at that point. Bytes after it are not seen. `file of Byte` reads every byte. |
| Circular `uses` in implementation parts | Allowed: `A` implementation uses `B`, `B` implementation uses `A` compiles and runs. |
| Circular `uses` in interface parts | `B.PAS(3): Error 68: Circular unit reference (A).` (line of the `uses` that closes the cycle). |
| Unit-qualified names | `U.K`, `U.V`, `U.T` (type), `U.F(2)`, `U.Hi`, assignment to `U.V`, and `System.Length('abc')` all work; a program variable `V` shadows `U.V` unless qualified. |
