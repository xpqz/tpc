# 109: README demo GIF and a live IDE on GitHub Pages

Branch 109-readme-demo-and-pages. Tooling and docs; no counted path changed (`tools/loc.sh`
unchanged: see below).

## Changes

- `site/coi-sw.js`: our own service worker; refetches each request and returns it with
  COOP `same-origin` and COEP `require-corp`. Status-0 (opaque) responses pass through.
- `site/index.html`: landing page. Registers the worker, waits for `ready`, seeds
  `tp5:DEMO.PAS` into localStorage only when no `tp5:` key exists, then `location.replace`s to
  `host/index.html?wasm=../ide.wasm&compiler=../tp5c.wasm` (relative: works under `/tpc/`).
  Design: a forward redirect instead of "reload once", so there is no reload loop to guard.
  The redirected navigation is answered by the active worker, so the host page is isolated.
  host/ is copied unchanged. The IDE starts empty (no startup file), so a visitor presses F3
  and opens DEMO; README says so. A hard reload (shift) of the IDE page bypasses the worker and
  loses isolation; reopening the landing page fixes it.
- `site/demo.pas`: Crt colour program (checked with the native compiler and `tests/run.mjs`).
- `site/deploy.sh`: fresh clone of gh-pages (or orphan branch) under `tmp/`, replaces the
  tree with `tmp/site/`, adds `.nojekyll`, commits, `git push origin gh-pages`. Not run.
- `Makefile`: targets `site`, `deploy-site`, `test-site`, `demo-gif` (own lines only).
- `tests/host/browser/plain_server.mjs`: static server without COOP/COEP, under a prefix.
- `tests/host/browser/site.mjs`: the site test (opt-in, `make test-site`): at `/` and `/tpc/`
  asserts `crossOriginIsolated`, then F3 DEMO, F9 "Compiled", Ctrl-F9 and the program's rows.
- `tests/host/browser/chrome.mjs`: exports `chromeBackend`; adds `screenshot(clip)`.
- `tools/demo_gif.mjs`: drives the built site in headless Chrome, screenshots the canvas
  (`Page.captureScreenshot`), builds `docs/images/ide-demo.gif`.
- `docs/images/ide-demo.gif`: 10 frames, about 18 s, 95 KB.
- `README.md`: GIF and live-demo paragraph.

## Deviation from the brief

`/opt/homebrew/bin/ffmpeg` does not start (dyld: libx265.215.dylib missing; x265 4.2 ships
.216). I did not alter the machine; the GIF is assembled with ImageMagick (`magick`) with a
shared 32-colour palette and frame optimisation. The script uses `$MAGICK` or `magick`.
