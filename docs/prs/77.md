# #77 IDE Keys

## Stage 1: RED

### Interface the tests fix (unit `Keys`, `ide/keys.pas`)

`uses Crt, Buffer, View` inside. The tests use only:

- `function ReadCommand: Integer`: blocks in `ReadKey` for one key (and for the second key of
  `^K`/`^Q`), edits the Buffer, clears the View message first (so a message set by the command
  stays until the next key) and returns a command code. Painting is the caller's job, except
  that the find prompt paints itself while it is open.
- `procedure ResetKeys`: no block, no find text, Insert mode (also run by the unit's
  initialisation). `View.Reset` and `ResetKeys` are separate calls.
- Command codes: `CmdNone = 0` (edit, cursor move, ignored key), `CmdSave = 1` (F2),
  `CmdOpen = 2` (F3), `CmdCompile = 3` (F9), `CmdRun = 4` (Ctrl-F9), `CmdMenu = 5` (F10, and
  Alt-F/E/R/C/O), `CmdQuit = 6` (Alt-X). `var MenuLetter: Char` holds `F E R C O` for the Alt
  keys and `#0` for F10. Keys never saves, opens or quits itself; Main does.
- Keys: arrows, Home/End (line start/end), PgUp/PgDn (23 lines, stops at the first/last line),
  Ins (Insert/Overwrite, shown by View's indicator), Del, Backspace, Tab (types `#9`), printable
  characters, Enter (inserts a break plus the blanks/tabs of the line being left that lie left
  of the cursor), `^Y` (deletes the line and its break), block `^K B / K / C / V`, find
  `^Q F` and `^L` (find again). `Alt-K` and `Alt-Q` stand for `^K` and `^Q` (decision 41); after
  the prefix the control form (`^K ^B`) counts as the letter; extended keys after a prefix, and
  unknown keys after it, are ignored. Unknown control codes (`^A`, `^J`, ...) and unknown
  extended keys type nothing.

Decisions fixed by the tests (to be recorded by the lead):

- One block of two marks `[BlockStart, BlockEnd)`; it counts as marked only when start < end.
  `^K C` copies it to the cursor, `^K V` moves it; afterwards the copy is the block and the
  cursor is at its start. Refused with a message when no block is marked ("No block marked"),
  when the cursor is strictly inside the block ("Cursor is inside the block") or the copy does
  not fit ("Not enough room", also for a move). The cursor at either end of the block is allowed.
  There is no separate clipboard: copy and move work from the marks.
- Any edit (typing, Del, Backspace, Enter, `^Y`) hides the block, so marks never point into text
  that moved; cursor moves keep it.
- Find: prompt `Find: ` on the status line (message area), Enter accepts, Esc cancels,
  Backspace edits, extended keys are ignored, 40 characters at most. Case-insensitive, searches
  forward from the cursor without wrapping, the cursor goes after the match, "Search string not
  found" otherwise. An empty answer (and `^L`) searches for the last text again.
- Overwrite replaces the character under the cursor except at a line end and at the end of the
  text, where it inserts; Enter always inserts. Full buffer: typing, Tab and Enter do nothing
  (no stray indent), Overwrite still replaces, `^Y` frees room.

### Tests (`tests/lang/ide_keys_*`, 51 programs; each has `.pas`, `.keys`, `.dirs` = `ide`, `.out`)

Each program is the editor loop: `View.Reset`, prefill the Buffer, `Paint`/`ReadCommand` until
`CmdQuit` (Alt-X, the last key of every script), logging non-editing commands in the status
message. The golden is the screen dump (rows, status line, cursor, attributes). Where the
dump shows no block, the effect of `^K C`/`^K V` is the observable.

- Cursor: `cursor_keys_home_end_and_wanted_column`, `..._at_the_ends_of_the_text`,
  `..._right_and_down_stop_at_the_end`.
- Typing: `typing_inserts_in_the_middle_...`, `backspace_and_delete_join_lines`,
  `tab_key_types_a_tab_and_control_codes_are_ignored`.
- Insert/Overwrite: `overwrite_replaces_but_inserts_at_line_end`,
  `overwrite_at_the_end_of_the_text`, `overwrite_does_not_eat_the_line_break`,
  `enter_in_overwrite_mode_inserts`; the indicator shows in the status line.
- Auto-indent: `enter_copies_the_leading_blanks` (blanks and tabs, indent-only line, repeated
  Enter), `enter_inside_the_indent_copies_only_the_blanks_left_of_the_cursor`,
  `enter_splits_a_line_and_indents_the_rest`.
- `^Y`: `ctrl_y_deletes_the_cursor_line`, `..._on_the_last_line_and_on_one_line`,
  `..._with_final_line_break_and_empty_text`.
- PgUp/PgDn: `page_down_and_up_in_a_long_text` (100 lines), `page_up_and_down_near_the_ends`
  (30 lines), `page_keys_in_a_text_shorter_than_a_page`.
- Block: copy later/earlier/across lines/twice, move forward/backward, at the block ends,
  cursor inside (refused), no marks or end before begin, empty block, begin moved, survives
  cursor moves, hidden by typing / Backspace / Del / Enter / `^Y`, Alt-K prefix, control forms
  and ignored keys after the prefix, copy and move refused in a full buffer.
- Full buffer: `full_buffer_ignores_typing_and_enter_but_overwrite_and_ctrl_y_work`. These three
  programs paint once at the end: a paint of a 65521-character buffer takes seconds under TP.
- Find: `find_moves_the_cursor_after_the_match_and_ctrl_l_repeats`, not found keeps the cursor,
  case-insensitive, no wrap-around, across lines and at the end of the text, Esc and Backspace,
  empty answer, Alt-Q / `^F` / ignored keys, extended keys in the prompt and the 40-character
  cut, find after an edit.
- Commands: `commands_are_returned_not_executed` (F2 F3 F9 Ctrl-F9 F10 Alt-F/E/R/C/O in one log),
  `commands_unknown_extended_keys_type_nothing`, `commands_do_not_disturb_insert_mode_or_the_text`.

Negative tests: the unit adds no language construct; the refusals above (no block, cursor
inside, no room, not found) are the error paths and each has a test.

### How the goldens were made

`.out` files come from `tools/tp5.sh` (real TP 5.0) compiling a **draft** `ide/keys.pas`
(339 lines, 339 counted; kept at `tmp/keys_draft.pas`, not committed). The draft found two
test bugs while the goldens were made (script token `Delete` is `Del`; a find script left a prompt
open and ended with exit 255), both fixed, and an uninitialised global (`MenuLetter`), visible in
TP as garbage in the status line; the draft now initialises it. With the draft in place all 51
programs are byte-identical from this compiler through `tests/run.mjs` (`cargo test --test lang`:
21 passed). I read the dumps for the block, find, indent, `^Y` and overwrite cases against the
intent. The draft was removed for this commit.
