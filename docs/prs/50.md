# #50 Host imports from external runtime routines

Branch: `50-host-imports-from-external-runtime-routines`

## Stage 1: RED

### Blocker for GREEN: the import `write` cannot be a routine named `Write`

Decision 29 names an import after its routine. `Write` is a predeclared intrinsic, and
System is checked from scope 0, so declaring `procedure Write(...)` in System is error 4
(duplicate identifier), line 0 (measured: appended to a copy of `runtime/system.pas` through
`compile_with`, `Err(Diag { code: 4, line: 0 })`). `rterror` (`RtError`) and `fmt_real`
(`Fmt_Real`) have no such clash. Options for the lead: (a) `external` takes an optional name
string in runtime sources only (`procedure HostWrite(...); external 'write';`), so import
names stay as in docs/abi.md; (b) rename the import (touches `tests/run.mjs`, the hand-built
modules in `runner.rs`, `nested.rs`, `wasm_*`, `phase0_exit.rs`, docs). The RED tests do not
depend on the choice: they use non-clashing names (`Beep`, `Alpha`, `Beta`, `Probe`, `Twice`).
`halt` is not emitted today (there is no `Halt`), so nothing to migrate.

### Design assumptions the tests pin (say if any is wrong)

- Import order is the order the mark phase first reaches each external; declaration order in
  System does not matter. `write` and `rterror` are reached up front (the always-emitted
  built-in functions call them), so they stay imports 0 and 1; hello-world stays 429 bytes.
- Parameters: integer-class scalars (Integer, Word, LongInt, Boolean, Char, enums) are i32;
  a `Real` parameter is an f64 by value (today ordinary routines take Reals by address).
  Results: integer-class scalar (i32) or none. `var` and aggregate/String parameters, and
  String/Real results, are rejected in System with error 200 (line 0). A Real result is not
  needed by any current import; supporting it would add a special case in `invoke` and `real`.
- `external` is accepted only in the embedded runtime source and only at top level; in user
  code it is error 200 at the `external` token (today: error 36, BEGIN expected).
