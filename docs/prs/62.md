Intended behaviour: `uses Crt` finds the embedded `runtime/crt.pas` (never a user `CRT.PAS`); its initialisation replaces
System's console writer and console line reader, so plain Write/WriteLn/ReadLn use the window, cursor and TextAttr; programs
without Crt compile to the same imports (and, checked in GREEN, the same bytes).
