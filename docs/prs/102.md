# #102 Wrong-type argument to a var Text parameter of a user routine gives 77, TP gives 26

Branch: `102-var-text-argument-error-26`.

## Probes (real TP 5.0, `tools/tp5.sh`; all `.err` files come from it)

- `procedure Show(var f: Text)` given an Integer, a String, a record, a typed constant: 26.
- The same parameter in a unit routine (`uses ShowU`), given an Integer: 26.
- `var s: String` parameter given a Text variable: 26 (already ours).
- `Show(f + 1)` with `f: Text`: 89.
- System routines given an Integer: `Reset`, `Close`, `Assign`, `Eof`, `Flush`, `SetTextBuf`: 77.
- `Addr(a + 1)` and `Addr(G + 1)` (G a function): 89 (`")" expected`); `Addr(1 + a)`, `Addr(-a)`,
  `Addr((a))`, `Addr(not b)`, `@(a + 1)`: 20. `Addr(G)` is accepted.
- A file-typed variable (`File`, `file of Integer`) is error 200 here (omitted feature), so no test of
  those as arguments.

binary expression that starts with an identifier is 89.
