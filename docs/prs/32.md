# #32 Compiler WASM API exports

Branch: `32-compiler-wasm-api-exports`.

## RED

- `compiler/tests/wasm_api.rs`: builds the release wasm32 lib, then runs `tests/wasm_api.mjs`
  with a lang program (`hello_string`) and a neg program (`assign_to_constant`); the
  expected error code, line and column come from the native `tp5c::compile`.
- `tests/wasm_api.mjs`: instantiates the compiler wasm, copies the source in via `alloc`,
  calls `compile`, runs the output with `run(bytes)` from `tests/run.mjs` and compares stdout
  with the `.out`; compiles the error source and checks `err_code/err_line/err_col`; compiles
  the good source again after the error.
- `compiler/tests/unsafe_guard.rs`: `unsafe` appears only in `ffi.rs`, never as a block, fn,
  impl or extern; `lib.rs` starts with `#![deny(unsafe_code)]`.

Before implementing, `cargo test --test wasm_api` failed with `missing export alloc` (the
build succeeded; the module had no API exports). LOC before: 2637 / 15000.

## GREEN

- `compiler/src/ffi.rs` (wasm32 only): `alloc`, `compile`, `out_ptr`, `out_len`, `err_code`,
  `err_line`, `err_col`; `memory` is exported by the cdylib. State is a thread_local
  `RefCell<State>`. `alloc` resizes the `Vec` that `compile` later reads, and `compile`
  checks `src_ptr` is that buffer, so no raw pointer is dereferenced and no `unsafe` block
  exists. `#[no_mangle]` is itself an unsafe attribute under `unsafe_code`, so the module
  carries `#![allow(unsafe_code)]`; the crate is `#![deny(unsafe_code)]` (a `forbid` cannot be
  overridden). `flags` is reserved and ignored. A pointer that is not the last `alloc` result
  returns status 1 with code 0.
- `compiler/src/lib.rs`: `forbid` to `deny`, `pub mod ffi` under `cfg(target_arch = "wasm32")`.
- `tools/budget.txt`: `ffi.rs` added to the Driver component.
- `tests/tools/loc_test.sh`: the pinned expectation of the Driver component's paths gains
  `ffi.rs` (required by the budget.txt change; no assertion weakened).

Commands: `make check` exit 0 (fmt, clippy, all tests, loc). `make wasm`: release
`tp5c.wasm` is 119,546 bytes (unstripped cdylib as built). LOC after: 2706 / 15000 (+69).
