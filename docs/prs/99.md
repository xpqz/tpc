# #99 Cheap missing standard routines

Branch: `99-cheap-missing-standard-routines` (pre-approved: tests and implementation in one pass,
no RED stop).

## Probes (real TP 5.0, `tools/tp5.sh`)

- `Addr(n) = @n`, type Pointer, assignable to `^Integer`.
- `DosVersion` is `$0005` (low byte 5, high byte 0).
- The oracle's environment has 3 variables (`PATH`, ...): `EnvCount` is 3, `EnvStr(0)` and `EnvStr` out
  of range are `''`, an unset `GetEnv` is `''`. Deviation D47.
- `TextMode(m)`: clears the whole screen (also outside a window), `TextAttr` becomes 7, the window the
  whole screen, the cursor 1,1, `LastMode := m` (`CO80 + Font8x8` gives 259 and a 50-line
  screen; `CO40`/`BW40` a 40-column one). `BW80`, `CO80`, `Mono` keep 80x25. Deviation D48.
- `Flush(f)` on an unassigned, assigned-closed or closed file is error 103; on an input file, the
  console files and `Input` it is accepted. `Flush(n)` for an Integer is 77.
- `AssignCrt(f)` then `Rewrite`/`Reset`: writes and reads go to Crt's screen and keyboard; `WhereX`/`WhereY`
  follow; windows and scrolling apply.
- Negative numbers: `Addr(5)` 20, `Addr` 88, `Addr(a, b)` 89, `Flush` 88, `Flush(f, 1)` 89, `GetEnv(5)` 26,
  `GetEnv` 88, `EnvStr('x')` 26, `DosVersion(1)` 89, `TextMode('a')` 26, `TextMode` 88, `AssignCrt(n)` 26.

## Changes

- `runtime/system.pas`: `Flush(var f: Text)`: error 103 for an unassigned or closed file, otherwise
  nothing (output is unbuffered, D31).
- `runtime/dos.pas`: `DosVersion`, `GetEnv`, `EnvCount`, `EnvStr` (D47).
- `runtime/crt.pas`: mode constants, `TextMode`, `AssignCrt` (= `Assign(f, '')`, the console Crt has
  hooked, decision 50 / D42), `FullWindow` shared with the initialisation.
- `compiler/src/{types,symbols,check}.rs`: `Addr` intrinsic, rewritten to the `@` node
  (`addr_call`), so `Addr` and `@` share every rule; counted as a function for the missing `(` error.
- `compiler/tests/crt_unit.rs`: the expected counts of `crt_*` corpus programs (46 to 51 lang,
  12 to 13 neg).
- `tests/neg/PENDING`: `assigncrt_of_integer`. Pre-existing divergence: this compiler gives 77
  (File variable expected) for any argument of the wrong type to a `var f: Text` parameter,
  including a user's or a unit's routine; TP gives 77 only for the System file routines and 26 for
  a routine declared in Pascal (`var_mismatch` in `check.rs` does not know the origin). Reproducer:
  `procedure P(var f: Text); begin end; var n: Integer; begin P(n) end.` Not fixed here, as the
  diagnostics are being changed in parallel.
- `docs/deviations.md`: D32 retired, D41 narrowed, D47, D48, D49. `docs/decisions.md`: 53.

## Omitted

`Erase` and `Rename` (SWAG 74 and 38): the VFS has no delete or rename import and Host glue is
600 / 600, so adding them is not line-neutral. Decision 54 and D49 record the contract to add
later. `Addr(a + 1)` is error 89 in TP and 20 here (not tested).
