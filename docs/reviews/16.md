Changes, all to be reflected in the tests before GREEN:

1. **Token kinds cost too many lines.** The `Tk` enum alone is 98 of 450 lines, and it
   needs a second table to map text to variants. Replace the one-variant-per-keyword and
   one-variant-per-operator design with: `Tk::Kw` (keyword; `text` holds the uppercase
   keyword) and `Tk::Sym` (operator or punctuation; `text` holds its canonical spelling,
   `(.` → `[`, `.)` → `]`), keeping `Ident`, `IntLit`, `RealLit`, `StrLit`, `Directive`,
   `Eof`. The keyword list becomes one packed `&[&str]` array. The parser will match on
   `(kind, text)`, e.g. `p.kw(b"BEGIN")`, `p.sym(b":=")`. Recorded as decision 9.
2. **Standalone `^X` control characters are legal TP5** (`c := ^M;`, `Write(^G)`). Decide
   by the previous token: `^` is the pointer operator after an identifier, `)`, `]` or
   `^`, and a control-character string otherwise. Add tests: `c := ^M;`, `Write(^G, 'x')`,
   `p^.x`, `a[1]^`, `f(x)^`, `p^^`.

Show the updated tests failing, then proceed to GREEN without waiting for another RED
verdict. Finish with `make check`; report the lexer line count.

## GREEN verdict: changes (review 2)

Verified on 8e6623a merged with main: `make check` clean, 84 lex tests, lex.rs 292 / 450.
The pointer guard for `^Integer` is accepted. The position-test correction (column 14
after the 12-byte string `'a'#13#10'b'`) is approved as a provable arithmetic typo.

One change. The real TP 5.0 (now available as `tools/tp5.sh`) accepts
`type PT = ^T;` as a pointer type and `c := ^M;` as a character, so TP decides by
parser context, and the lexer limitation would reject valid programs. Fix by giving the
parser the choice:
1. A standalone `^X` that the lexer would turn into a control character, and that is not
   joined to other string pieces, becomes a new kind `Tk::Ctrl` whose `text` is the single
   original character (`M` for `^M`, `[` for `^[`). The parser treats `Ctrl` as a char
   literal (value `c ^ 0x40`) in expressions and as `^` + type identifier in type context.
   Joined forms (`'a'^M`, `^M'a'`, `^M#10`) stay a folded `StrLit` as now.
2. Tests: `type PT = ^T;` lexes `... Sym "=", Ctrl "T", Sym ";"`; `c := ^M;` gives
   `Ctrl "M"`; `^M'a'` and `'a'^M` stay one `StrLit`; the existing pointer cases unchanged.
Show the new tests failing first, then implement. `make check`, report.
