# Review #93: IDE host test can hang

## Verdict: approve (review 1)

Cause found and shown: asynchronous `WebAssembly.compile` in tests/run.mjs sometimes never
settles on Node 23.8.0 under load (logging bracketed the await; 0% CPU waiting on a V8
task). The runner now compiles synchronously. Every node, sh and tp5c child spawned from
cargo tests has a 300 s hang guard that kills the child and fails with its output, itself
tested. Stress: 30/30 concurrent pairs, 3 x 48 concurrent copies, 5 x cargo ide_host,
`make check` exit 0.
