# Review #47: Readability review of the compiler

## Findings verdict: approved, proceed to fixes (review 1)

The findings list (docs/prs/47.md) is accepted in full, in the suggested reading order.
Rulings on the open decisions:

- **C2: replace the generate-until-stable loop with mark-then-emit.** Neither "always
  import" nor "document the loop". Before emitting, walk the checked AST from the roots
  (main, unit initialisers later, address-taken routines) and collect every reachable
  routine, helper, import and literal; then assign indices (imports first, then defined
  functions) and emit. This is the textbook two-phase DCE, it removes every index shift,
  and decision 29 (`external` runtime routines as host imports, emitted when reachable)
  builds directly on it. Modules may differ in function order; tests that pin bytes
  across unrelated programs must still hold; hello-world stays within the 2 KB target.
- **T9: yes**, a payload per `SymKind` instead of the overloaded `Symbol::val`.
- **A2: yes**, named fields for the multi-field `Kind` variants (`For`, `Routine`,
  `Param`, `Fmt`, and any other with three or more positional fields).
- **W6: remove** `i64_const`, `br_table`, `I64`, `TABLE` and the tests that exist only for
  them (YAGNI; re-add with a test if ever needed).
- **L6: fix** the `END .` stop check to require keyword kind, with a regression test
  (`'END'.` in a string must not stop lexing).

Process: behaviour-preserving commits in the suggested order, `make check` green after
each, every commit message naming the findings it addresses. Report the LOC delta per
component at the end. No component may exceed its budget; if one would, stop and report.
